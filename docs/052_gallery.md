# 052 飯田の風景を見る（ドット絵と写真を見比べるギャラリー）

- 主な要件：F-01（えらぶ）、7.3（出典・注意書き）、8章（見た目・PWA）
- 依存：016、024、028、050
- 見本：`docs/design/gallery-pc.png`・`docs/design/gallery-mobile.png`（風景の画像はサンプル。並び方と部品は見本どおりに作る）

## 目的

えらぶ 01 の飯田市全体の絵（050 で動画の目印を立てた絵）から、4地区の風景を写真で一覧し、ドット絵と本物の写真を見比べられるようにする。050 の動画を閉じたあとも、見た場所をじっくり見返せるようにする（2026-11-24 まさゆきさん）。049 のデモ動画には足さない。

## 画面（見本の要素。省かない）

1. **地区を選ぶ（えらぶ 01）**
   - PC：全体の絵の右上に白い札「🖼 飯田の風景を見る」
   - スマホ：見出し「どの地区で暮らす？」と絵のあいだに、緑の横長ボタン「🖼 飯田の風景を見る」
   - 絵の下に「〈場所の名前〉をじっくり見る →」。動画をまだ見ていないときは出さず、最後に見た場所の名前で出す（押すとその場所の見比べる窓を開く）
   - 地区の選択肢（PC は右に縦1列、スマホは 2×2）と「次へ」は今のまま
2. **写真一覧（窓。右上に ×）**
   - 見出し「飯田の風景を見る」
   - タブ「すべて／上郷／鼎／伊賀良／中心市街地」で絞り込む
   - 地区名の下に写真カード（写真と場所の名前）。PC・スマホとも2列
   - 写真のない地区（鼎・伊賀良）は、地区名の下に「準備中です」
3. **見比べる（窓）**
   - 「← 写真一覧へ」と ×、地区名、場所の名前（大きく）
   - 「実際の写真／ドット絵／見比べる」の切りかえ。はじめは「見比べる」
   - 見比べる：左がドット絵、右が写真。境目の「‹ ›」を左右に動かす（マウス・指・キーボード）。左上に札「ドット絵」、右上に札「実際の写真」。はじめは真ん中
   - 絵の下に「境目を左右に動かす」（スマホは「指で境目を左右に動かす」）、その下に小さく「写真：開発者が撮影（2026年11月）」
   - いちばん下に「← 前の場所」「次の場所 →」
   - PC は横長の枠（16:9 のまま）。スマホは画面幅いっぱいで縦に近い枠にし、絵と写真の真ん中を同じ範囲で縦長に切り出して見せる

## 決まっていること（2026-11-24 まさゆきさん）

- 写真のない地区は「準備中です」
- スマホの見比べる枠は、真ん中を縦長に切り出す
- 生成AIで描いたことは書かない。撮影者は「開発者」、撮った月は 2026年11月（5枚とも）
- 「〈場所〉をじっくり見る →」は、動画を見る前は出さず、最後に見た場所の名前で出す
- 画像はデータベースに入れず、サイトのファイル（`public/` の下）として公開する。画面用に WebP にする
- Claude が決めたこと（違えば直す）：「前の場所／次の場所」は選んでいるタブの中で順に回る（「すべて」なら全地区を通す）。窓を開いた状態は URL に残し、スマホの「戻る」で一覧へ戻れるようにする

## 作ったもの（2026-11-24）

- 画像：元の10枚は `assets/illust/gallery/`。`npm run illust` が場所ごとにドット絵と写真を同じ 1440×810（16:9）にそろえ、横幅 480・960・1440 の WebP を `public/illust/gallery/<場所>-<pixel|photo>-<幅>.webp` に書く（30枚・約5.3MB。撮影情報は書き出しで落ちる）
- 場所の名前と画像：`src/lib/illust/photo-spots.ts`（`gallery`・`GALLERY_*`・`galleryImageSrc`）。動画の目印の読み上げも新しい名前になった（例「上郷の飯沼神社：絵が本物の写真に変わる動画を見る」）
- 決めごと（タブ・URL・前後の場所）：`src/lib/gallery/gallery.ts`。URL は `g`（タブ：all・地区）と `gs`（場所）。条件の `p`（大切なこと）とぶつけないためこの名前にした
- 画面：`src/components/gallery/`。窓は `SceneryGallery`（<dialog>。一覧と見比べる）、絵は `CompareFrame`、URL の移り方は `useGalleryRoute`
  - 開く・一覧から場所を開くは履歴に足し、タブ・前後の場所は置きかえる。× は足した分だけ履歴を戻る（閉じたあとの「戻る」で窓がまた開かない）
  - 境目：マウスは押したところへ動き、引っぱれる。指は横に引っぱると動き、縦はスクロール。キーボードは ← → ↑ ↓（5%）・Page Up/Down（10%）・Home/End。読み上げは「ドット絵と写真の境目」「ドット絵 50%、写真 50%」
  - 「指で境目を左右に動かす」は指で触る端末（`pointer: coarse`）で出す。マウスの端末は「境目を左右に動かす」
  - スマホ（640px 未満）の枠は 19:20。2枚とも真ん中を同じ範囲で切り出す。「実際の写真」「ドット絵」でも同じ枠
  - 一覧のカードは写真（スマホは正方形、PC は 16:9）。地区のまとまりは縦に並べ、カードを2列にした
- えらぶ 01（`ErabuFlow`）：PC は絵の右上の白い札、スマホは見出しの下の緑のボタン。スマホの地区の質問は、見本どおり見出しを絵の上に移した（説明の一文「気になる場所から、はじめよう。」は残した）。「〈場所〉をじっくり見る →」は動画を開いた場所を覚えて出す（画面を読み直すと消える）
- PWA：ギャラリーの画像は Service Worker が先に残さず、見たものだけを残す（`/illust/` は前から使ったときに残す決まり）。見たことのある場所は圏外でも出る。コードの変更はなし
- 2026-11-24 窓にふわっと出る動きを付けた（まさゆきさん）：開くと少し下から浮かび上がって出て（0.42秒）、× ・Esc・後ろを押すと少し沈みながら消えてから閉じる（0.22秒）。一覧 ⇔ 見比べる・前後の場所では中身だけをふわっと出し直す（0.32秒）。「動きを減らす」では動かさない。tailwind の `gallery-in`・`gallery-out`・`gallery-view-in`。見せ方（実際の写真など）は場所を移っても変えないよう、窓の側で持つ
