# 009 市オープンデータの取り込み（避難場所・公共施設・補完データ）

- 主な要件：7章（避難場所・公共施設・学校/保育の補完）、7.3（PDL1.0 の出典表記）
- 依存：004、005

## 目的

飯田市オープンデータ（PDL1.0）から、指定緊急避難場所・公共施設・教育機関・子育て施設を取り込む。

## 仕様メモ

| データ | 入手先 | 更新 |
| --- | --- | --- |
| 避難場所 | 市「指定緊急避難場所一覧」（2025-12-19更新） | 年1回 |
| 公共施設 | 市「公共施設一覧」（2025-06-23更新） | 年1回 |
| 学校の補完 | 市「教育機関一覧」 | 年1回 |
| 保育施設の補完 | 市「子育て施設」（2024-11-05更新） | 年1回 |

- 出典表記は「出典：飯田市オープンデータ『指定緊急避難場所一覧』を加工して作成」のようにデータ名ごとに書く。書き方は市の「PDL1.0に関する重要情報」に合わせる
- 公共施設は「暮らしに関係するもの」に絞る。載せる種類はデータを見てから決める（2.2）
- CSV の取得 URL が固定なら Worker で自動、そうでなければ手動取り込みのスクリプトにする
- 緯度経度がない行は住所から求めるか、地図に出さずに一覧だけにするかを決める
