# 046 くらしの絵の上のぽてりを、自由に動かせるようにする

- 主な要件：8章（見た目・スマホ。タップ領域は 44px 以上）
- 依存：042（マスコット）、043（一人のときのぽてり）、018・028（くらしの絵）

## 目的

2026-11-20 まさゆきさん：くらしの絵の上のぽてりを、さわって自由に動かせるようにしたい。PC はドラッグ、スマホは押しっぱなしにして動かす。
移住とは関係ないが「なんか気になって、さわりたくなる」もの（042 の考え）を足す。

## 決めたこと（2026-11-20 まさゆきさん）

- **PC**：ぽてりをつかんで、ドラッグで動かす。動かさずにクリックしたときは、今までどおりエプロンの色のパレットを開く。少しでも動かしたら「動かした」とみなし、パレットは開かない
- **スマホ**：ぽてりを少し（約0.4秒）押しっぱなしにすると、少し浮いて「持ち上げた」ように見え、そのまま指で動かせる。さっと押して離したときは、今までどおりパレットを開く
- 動かせるのは絵の中だけ（絵の外には出さない）。ピンより下に重ねる（ピンを押すじゃまをしない）
- **動かした場所は覚えない**。ページを開き直す・季節や地区を切りかえると、元の場所（`src/lib/mascot/spots.ts` の地区ごとの場所）に戻る。地区ごとに似合う場所を選んであるため
- **離したときは、少しはねて着地する**動きを付ける。そのあとは、その場所でいつものしぐさを続ける

## 作るときの注意

- 対象はくらしの絵の上のぽてり（`Mascot`）だけ。カルテ・地区くらべ（`MascotFigure` を直接使う所）と、一人のときの「わが家」のぽてり（`MascotCompanion`）は動かさない
- Pointer Events で作り、新しい道具（ライブラリ）は足さない。マウスとタッチを同じ処理で扱い、スマホだけ「押しっぱなしで持ち上げる」を足す
- スマホ：持ち上げている間だけページのスクロールを止める（`touch-action` と、持ち上げたあとの `preventDefault`）。持ち上げる前に指が動いたら、ふつうのスクロールにする（絵の上をなぞってスクロールする人のじゃまをしない）
- iPhone の長押しで出る画像の保存メニュー・文字の選択を、ぽてりの上では出さない（`-webkit-touch-callout: none`・`user-select: none`）
- 位置は絵に対する割合（％）で持ち、画面の幅が変わってもずれないようにする。今の置き方（足元を `-translate-y-full` でそろえる）を変えず、足元の場所を動かす
- 持ち上げている間は少し浮かせて大きくし、パレットが開いていたら閉じる
- はねて着地する動きは `tailwind.config.ts` の keyframes に足す。「動きを減らす」では、はねずにそのまま置く
- キーボードと読み上げ：動かすのは飾りの遊びなので、キーボードで動かす操作は足さない。ボタンは今までどおり「押すと服の色を変えられます」のまま（今の aria-label は変えない）
- 地区・季節を切りかえたら元の場所に戻す（部品をその地区・季節ごとに作り直すか、位置を消す）
