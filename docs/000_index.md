# チケット一覧

`REQUIREMENTS.md`（要件定義書 v2.0）と `REQUIREMENTS.pdf`（図解入り）をもとに、要件・機能ごとに分けた作業チケット。番号はおおよその着手順で、依存関係は各チケットの「依存」に書く。Todo の書き方は `CLAUDE.md` の「チケットとTodoの管理」に従う（未完了 `- [ ]`、完了 `- [×]`）。

デザインは `docs/design/`（スマホ版・PC版）を**イメージ**として参照する。色・余白・部品の雰囲気の参考にとどめ、文言や項目は要件定義書を正とする。

## 進め方（要件 11.2）

確認済みデータ（相場・学区・学校・保育・避難場所・公共施設）だけで動く版を先に作り、行事・人口・バス停などの未確認データは確認できた順に足す。
