# 050 地区の絵が写真に変わる動画（Google の AI・Veo）

- 主な要件：1.1（コンテストへの応募）、F-01（えらぶ）
- 依存：016、028、049

## 目的

Google AI Challenge のデモ動画（049）で「Google の AI を活用しているシーン」を見せるため、Google の動画生成AI「Veo」で作った動画をサイトに足す。えらぶの最初の質問（住む地区）の飯田市全体の絵で4地区の場所を押すと、そこのドット絵風の絵が本物の写真に変わっていく動画を見られる。

## 決まっていること（2026-11-23 まさゆきさん）

- **動画は前もって作る**。まさゆきさんが Google Flow か Gemini アプリの Veo で4地区分（4本）を作り、サイトはその mp4 を流すだけ。見る人の待ち時間・費用はなし。画面から Veo の API は呼ばない
- **最後に映る写真は、まさゆきさんが撮った写真**（4地区それぞれ）。Google マップ・ストリートビューの画像は規約で使えないので使わない
- **はじめの絵は、飯田市全体の絵（`assets/illust/common/erabu-iida-overview.png`）のその地区のあたりを切り出したもの**。Veo の最初の1枚にこれ、最後の1枚に写真を渡して、間をつないでもらう
- **見せ方は窓**。全体の絵で地区の札を押すと、画面の真ん中に窓を出して動画を流す（音なし）。窓の下に「この地区にする」と「閉じる」
- 049 の動画の「AI を活用しているシーン」は、Flow（または Gemini）で動画を作っているところの画面録画と、サイトで流れるところの録画
