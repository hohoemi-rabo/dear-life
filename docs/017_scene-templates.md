# 017 場面のテンプレートエンジンとひな形

- 主な要件：6章（くらしシミュレーションのルール）、6.3（テンプレート方式）、6.4（文の種類と見せ方）、9.5（場面のひな形テーブル）
- 依存：003、014、015

## 目的

季節×条件ごとの文章のひな形にデータを差し込み、3〜5文の場面の文章を作る仕組みと、最初のひな形一式を作る。

## 仕様メモ

- ひな形は「季節×条件（子どもの有無・車・家）」ごとに `scene_templates` / `scene_sentences` に持つ
- 文ごとに種類を持つ：**データ**（出典の印）／**地区の情報**（確認日）／**想定**（見た目を変える）
- 差し込み部分：`{地区名}` `{施設名}` `{住所}` `{件数}` `{学校名}` など。差し込む値が無いときの扱い（文ごと出さない／「データ未取得」）を決める
- 同じ条件なら何度見ても同じ文章（ランダムにしない・AI で作らない）
- 想定の文には数字・施設名・地区の評価を入れない（保存時にチェックする）
- 「家から近い」「歩いて◯分」のような距離の書き方はしない
- 行事を「義務」「負担が重い」などと評価しない
- ひな形はまさゆきさんが確認してから公開（公開フラグ）

### 季節と場面の軸（6.1）

| 季節 | 場面の軸 | 主に使うデータ |
| --- | --- | --- |
| 春 | 入園・入学（子ども0人なら地区の公共施設） | 学区、学校、保育園・幼稚園等、公共施設 |
| 夏 | 大雨と避難 | 指定緊急避難場所 |
| 秋 | 地区の行事 | 地区の行事、地区の人口 |
| 冬 | 雪・凍結と移動 | バス停と時刻、電車の駅と時刻、車の台数、長野県の移住情報（冬の路面凍結） |

例（春・子どもあり）：「4月、入園の季節です。{地区名}には保育園・幼稚園等が{件数}か所あります。たとえば{施設名}（{住所}）です。小学校は主に{学校名}の学区になります。」

### 冬・車0台の「おでかけ」（6.3）

- 時刻表の本物の便を差し込む：`{行き先}` `{乗り場}` `{発車時刻}` `{降り場}` `{到着時刻}` `{本数}` `{帰りの発車時刻}` `{次の便の時刻}`。値は 010・026 で保存したものを使う
- 差し込む便がないとき（成り立つ便がない／データの有効期間切れ）は、作らずに「この条件で使える便は見つかりませんでした」「データ未取得」を出し分ける
- この文から gofreely と、カルテの交通カードへ移れるようにする
- 010 で保存した値（`bus_outings`）の使い方と、次の便がないとき・24時を超える時刻の扱いは、010 の「017・018・019・021・022 への引き継ぎ」を見る

例（冬・車0台）：「土曜日、バスで{行き先}へ出かけます。{乗り場} {発車時刻}発 → {降り場} {到着時刻}着。このバス停からは土曜1日{本数}本です。帰りは{帰りの発車時刻}発、次の便は{次の便の時刻}です。」

## 決めたこと（2026-10-26）

- **差し込む値がないとき**：文ごとに、差し込む値を「出す／該当なし／データ未取得／この地区には当てはまらない」で見る
  - データ未取得が1つでもあれば、文を出さずに「◯◯：データ未取得」の知らせにする（言いかえで隠さない）
  - 該当なしなら、文の `fallback_body`（言いかえ）を出す。言いかえがなければ「◯◯：該当なし」の知らせ。便は「この条件で使える（バス／電車）の便は見つかりませんでした」、行事は「この季節の行事は準備中です」
  - 当てはまらない（駅のない地区の電車の文）は、文も知らせも出さない
  - 同じ話題・同じ状態の知らせは場面の中で1つにまとめる
- **本文に書いた事実の出典**：差し込みでなく本文に書いた事実（冬の路面凍結）は、文の `source_id` に出典を持つ。出典が未公開なら「データ未取得」
- **「たとえば◯◯」の施設**：`screen_data()` が返す固定の並び（種類・名前の "C" 順）の中で、
  - 保育施設：認可外保育所・その他（病児保育など）以外の最初のもの。それしかなければ最初のもの
  - 公共施設：公民館 → 図書館 → そのほか の最初のもの
  - 避難場所：洪水と土砂災害の両方に使える最初のもの
- **行事**：その季節の行事を並び順で最大2つ（`selectSceneEvents`。018 の行事の欄もこれを使う）。秋・子どもありは子ども向けを先にする。文にはいちばん目を入れ、区ごとの行事は「（区によって違います）」を付ける
- **バスの本数**は行き先へ乗りかえなしで行く便の数（`outbound_trips_per_day`、010 の引き継ぎどおり）。電車は特急を除いた数
- **注意書き**：春・子どもあり＝学区の注意、秋＝行事の注意、冬・車0台＝「本数や時間帯によっては、車なしの暮らしが難しいことがあります。」（`NOTICES.carFree`）
- **文の数え方**：ひな形の1行を1文と数える（おでかけの行は2文をつなげている）。全条件で3〜5行になることを `checkTemplates` で確かめる
- 公共施設と冬の凍結の文はカルテに当てはまるカードがないので、リンクなし（019 で公共施設のカードを足すなら付け直す）
- おでかけの行が2文をつなげて長いこと、施設名にかっこがあると「一色公民館（鼎一色公民館）（住所）」のように重なることは、今のままでよい（2026-10-27 まさゆきさん）

### 公開の手順（まさゆきさんの確認のあと）

1. `drafts.ts` の確認したひな形の `reviewed_on` に確認日を入れる
2. `npm run scenes:sql` → `npm test` → Supabase MCP の `apply_migration` で当て、ファイル名を `list_migrations` の版番号に合わせる
3. 画面に出るのは、ひな形と、使う出典の両方が公開されてから（出典の公開は 022）
