# 022 データについて ページと共通の注意書き

- 主な要件：F-08（データの説明）、F-09（データ未取得の表示）、7.3（クレジット表記と禁止事項）、8章（表示の注意書き）
- 依存：015

## 目的

出典と集計方法をまとめたページを作り、全画面の注意書き・クレジットを要件どおりにそろえる。

## 仕様メモ

- データごとの出典・対象期間・確認日（`data_sources` から出す）
- 除外した取引（調停・競売等／関係者間取引／隣地の購入）と件数、相場の集計方法（5章）
- 行事の集め方（10.1）と「年によって変わることがあります」
- 利用上の注意：相場は過去の取引の参考値、地図の位置は目安、支援制度は公式で確認、行事は年によって変わる
- クレジット（7.3）：
  - 不動産情報ライブラリ：利用約款で指定された文言をそのまま使う。公開前に約款の文言と一字ずつ照合する
  - 飯田市オープンデータ：データ名ごとに「出典：飯田市オープンデータ『…』を加工して作成」
  - GTFS：配布ページの表記（010 で確定）
  - 地区の行事：「地区の行事は、飯田市の公民館資料や地区公民館の情報をもとに独自にまとめたものです。年によって変わることがあります」＋資料名・確認日
  - 地理院タイル（021 で確定）
- 「個人が公開データをもとに作成したもの」であること。国や市のサービスだと誤認させない
- アクセス解析を入れる場合は、個人を特定しないものに限り、その旨を書く
- 「該当なし」「データ未取得」の表示部品を全画面で共通にする

## 確かめたこと（2026-10-27）

- **API 利用約款 第7条**（https://www.reinfolib.mlit.go.jp/help/termsOfUse/ ）の文言と、`data_sources` に入れていた文言を、ページから取り出してプログラムで比べ、一字も違わないことを確かめた。「エンドユーザが参照できる場所であれば、表示場所の指定はありません」
- 同じページの「コンテンツの利用に係るPDL1.0に関する重要情報」で、API の文言とは**別に**、コンテンツの出典（記載例「出典：国土交通省　不動産情報ライブラリ（URL）」）と、加工したときは「コンテンツの名称」と加工したことを書くよう求めている。また、国土数値情報は**この利用ルールの対象外**で、国土数値情報の利用ルールに従う
- 国土数値情報の利用規約（https://nlftp.mlit.go.jp/ksj/other/agreement.html ）の記載例は「「国土数値情報（○○データ）」（国土交通省）（当該ページのURL）をもとに○○作成」。小学校区（A27）・中学校区（A32）の令和5年度は「オープンデータ（CC BY 4.0（一部制限））・利用条件のある一部市区町村を除く」で、市区町村別の利用条件の一覧（`R5_Terms_of_use_municipality_data.xlsx`）で、飯田市は小・中学校区とも「公開・オープンデータ公開・特記条件なし」
- 対象期間（2021Q1〜2026Q1）の取引は市全体 1,313件、4地区 792件。そのうち除いたのは7件（調停・競売等 6件、関係者間取引 1件、隣地の購入 0件）。市全体では13件（4地区の外に調停・競売等 5件、隣地の購入 1件）

## 決めたこと

- **クレジットの置き場所**：出典ごとの文言は `data_sources.credit_text` を正にし、データについてページでそのまま出す。どの出典にも属さない文言（API 第7条・「個人が作成」・行事・地理院タイル）は `src/lib/credits.ts` に置く。API 第7条の文言はサービス全体の表示なので、出典の行から外して全画面の下とデータについてページに出す
- **XIT001 のクレジット**を利用規約の記載例どおり「出典：国土交通省 不動産情報ライブラリ（URL）。「不動産価格（取引価格・成約価格）情報」（国土交通省）をもとに、地区ごとの真ん中の値・幅・件数を計算して作成」に直した。学区（XKT004・005）は国土数値情報の記載例に直し、利用条件も国土数値情報の規約にした。XKT006・007 は公開しないので元のまま
- **除外した取引の件数**は、取引の表を anon から読めないので、`refresh_market_stats` が相場と同じ期間で数えて `market_summary`（1行）に入れる。理由は取引の事情を「、」で分けた語で数える（Worker の `EXCLUDED_CIRCUMSTANCES` と同じ）。1件が2つの理由に当たることがあるので、理由ごとの合計は除いた件数と合わないことがある（ページにも書いた）
- **公開した出典**（2026-10-27）：相場（XIT001）、学区（XKT004・005）、市の教育機関一覧・子育て施設・指定緊急避難場所一覧・公共施設一覧、バスの GTFS、SENA の駅、国勢調査、楽園信州の自治体紹介シート（冬の場面の雪と路面凍結の文。利用条件の記載はないが、事実を自分の言葉で書き、出典を示すだけなので公開した）。**公開しない**：電車の時刻（市の許可待ち、026）、XKT006・007
- 「該当なし」「データ未取得」の説明の文言は `dataStateDescription`（`DataStateMessage.tsx`）だけに置き、地区くらべ・地図・データについてページは `DataStateLegend` で出す。データ未取得は「出典の確認や取り込みが済んでいないため、まだ出せません。」にした。1つの画面に何度も出るので、各メッセージにはデータについてへのリンクを付けない（全画面の下からつながる）
- 行事の欄（くらし・地区くらべ）の注意書きは、要件 7.3 の文言（`EVENTS_CREDIT`。「年によって変わることがあります」を含む）にした
- アクセス解析は入れていないので、データについてページにそう書いた。入れるときはここを直す
