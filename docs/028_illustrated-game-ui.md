## 目的

027 で画面をモックに寄せたが、まさゆきさんの評価は「ワクワク感がない。文字が多すぎて説明っぽい」（2026-10-29）。システムの画面ではなく、ドット絵が主役の画面にする。説明は減らし、気になるところをタップしたときにだけ出す。数字の正確さと出典は崩さない（1章のギャップの「本物」の側）。

デザインの見本は `docs/design/` の4枚（2026-10-28 追加。一覧は `docs/design/README.md`）：

- `erabu-01-district-family-house.png`：えらぶ 01 地区・02 家族・03 家
- `erabu-04-05-car-priorities.png`：えらぶ 04 車・05 大切なこと
- `erabu-mobile-and-kurashi-pc.png`：えらぶ（スマホ）とくらし（PC）
- `kurashi-mobile-pins.png`：くらし（スマホ）。ピンをタップすると下からシートが出る

絵の元の画像は `assets/illust/`（一覧は `assets/illust/README.md`）。

## 決めたこと（2026-10-29 まさゆきさん）

- **UI/UX は上の4枚の画像のとおりにする。これは絶対条件**：見本に出ているもの（ピン・地区の札・印など）は省かない。位置や画像が分からないときはまさゆきさんに聞く。古い見本（`pc_design-concept.png`・`mobile__design-concept.png`）は消した。カルテは今のまま（027 の形）
- **実装はまさゆきさんの許可をもらってから始める**（チケットを作ったら、実装に入る前に必ず聞く）
- **選ぶたびに絵ができあがる**：えらぶの「わが家のプレビュー」は、背景だけの絵に、選んだ家族・家・車を重ねていく。01〜05 の流れの中で絵が変わる
- **画像はまさゆきさんが生成AIで作った部品を重ねる**（背景＋人物・家・車の透過PNG）。何かを見本にしたものではない。`npm run pixel`（コードで描いた 160×90 の絵）は、用意された画像に置きかえる。どの画像が要るかは、実装しながら Claude が1枚ずつ名前を決めて頼む（似た画像が多いので、まさゆきさんがまとめて名前を付けない）
- **人物**（2026-10-29）：大人1人目はお母さん、2人目はお父さん（大人1人のときはお母さん）。子ども1人目は赤い服の男の子、2人目はおさげの女の子。黄色の服の男の子とボブの女の子は使わない。人数を増やしたときは、その人がよろこぶポーズ（跳ねる・手を振るなど）でぽんと出て、立つポーズに戻る。05 まで進んだら全員を手を振る・親指などのポーズにする
- **01 の飯田市全体の絵には、見本どおり4地区の札と、選んだ地区のピンを出す**。地区の場所は `assets/illust/iida-districts-guide.png`（赤：上郷、青：中心市街地、オレンジ：鼎、紫：伊賀良）で決める
- **人物は最大4人（大人2・子ども2）、車は最大2台**。選べる人数も大人1〜2人・子ども0〜2人にする（絵と条件がいつも一致するように）。車は「0台・1台・2台以上」のまま、絵は2台まで
- **えらぶの絵に季節を出さない**：01 は飯田市全体の風景と、地区の選択肢の絵（まず上郷）。02〜05 は季節感のない上郷の風景に、家族・家・車を重ねる（季節を選ぶ前なので、春を強調するとおかしい）。季節が出るのはくらしから
- **まず上郷・春だけで試す**。用意するのは上郷の絵と、くらしの春の背景だけ。様子を見てから、ほかの地区・季節を用意するか決める（全部用意して作り直しになるのを避ける）。それまでほかの地区・季節は今の絵のまま
- **くらしの場面の文はピンのシートに移す**：風景の上のピン（学校・地域の行事・住まいなど）をタップすると、下からシートが出て、文・出典・カルテや地図へのボタンを出す。上郷の行事は、行事の場所にできる施設の絵がある
- **演出**：選んだときに人物・家・車が「ぽん」と出る動きと、キラキラの飾りを入れる。音は入れない。端末の「動きを減らす」（`prefers-reduced-motion`）では動かさない
- **フッター**：「データについて」はひと言とリンクだけにして、詳しくはそのページで見せる。フッターの高さを小さくする
- **上郷を作りこむ**：上郷ができるまで、見本どおりを絶対ルールにして上郷だけを作りこむ。鼎・伊賀良・中心市街地の選択肢の絵は今のドット絵のまま（仮）。上郷以外を選んだときの 02 以降のプレビューは、飯田市全体の絵の上に家族を並べる（背景がないとプレビューが組めないため。Claude の案をまさゆきさんが了承）
- **画面の上の部分（えらぶ）**：`erabu-01-district-family-house.png` のとおり、ロゴの下に番号の丸5つを線でつなぎ、名前を付ける。`erabu-mobile-and-kurashi-pc.png` の「わが家の準備 3/5」の棒と「≡」は使わない
- **地区の札の色**（2026-10-29 まさゆきさん、01 を見て）：選んだ地区は明るい薄緑に白い枠、選んでいない地区は暗い濃い緑。01・02 はこれで OK
- **地区の札の位置**：`iida-districts-guide.png` で囲った範囲の真ん中に置く。囲いの外（左下の隅、上の帯）は4地区の外として扱う。細かい位置は実装後にまさゆきさんが見る

## 計画：えらぶ 01・02（最初の段階。2026-10-29）

作り終えたら 375px と PC の幅でスクショを撮り、見本と並べて見せて止める。

1. **絵の下ごしらえ**（`npm run illust`）：`assets/illust/` から画面用の WebP を `public/illust/` に書き出す。背景は幅1536px と768px。キャラクターのシートは透明な隙間で1人ずつ切り分け、「どのシートの何番目が誰のどのポーズか」の対応表を1か所に置く。sharp を開発用の依存として足す。絵は本当のドット絵ではないので、整数倍の表示にせず、ふつうに縮めて出す
2. **わが家のプレビュー**：背景に人物を、絵に対する割合（％）の位置で重ねる。左上に「わが家のプレビュー」の札。増えた人はよろこぶポーズでぽんと出てキラキラ、1秒ほどで立つポーズに戻る。減った人はすっと消える。「動きを減らす」では動かさない
3. **01 地区**：「どの地区で暮らす？／気になる場所から、はじめよう。」。飯田市全体の絵に4地区の札（伊賀良は縦書き）、選んだ地区に緑のピン。札も押して選べる。選択肢は2×2の絵のカード（上郷は `district-kamisato.png`）。選んだら「上郷を舞台に、暮らしをつくります。」と「ここで暮らしてみる →」。地区の返事のカード（範囲・土地の値段）は見本にないので外す（相場は 03 で出す）
4. **02 家族**：「何人で暮らす？／一緒に暮らす家族を、迎えよう。」。上郷の風景の手前の広場に家族。大人・子どもの「−・＋」を横に並べる（＋は金色）。人数の範囲は大人1〜2・子ども0〜2（URL は丸める。子ども3人の家族のドット絵は消す）。小さな家族の絵と「人数を変えると、家族も変わります。」。返事はピンクの小さなカード（保育園・幼稚園等の数・小学校の数と出典）。「← もどる」「家族で、次へ →」
5. **画面の上の部分**：番号の丸5つ（終わった質問は ✓）。選んだ条件のチップは 01〜04 では出さない（05 の帯は 05 で作る）
6. **要件として守るもの**：出典、「該当なし／データ未取得」の区別、44px、横スクロールなし、「対象地区」の表示（小さくしたフッターに残す）
7. **テストと確認**：人数の範囲・URL の丸め・流れ・札で選べること・切り分けの対応表。lint・typecheck・test。表示の速さを 027 と同じやり方で測る
8. **ui-ux-pro-max スキルの使い方**（2026-10-29 まさゆきさん了承）：実装に入るときに読み込み、見本に描かれていないところ（動きの速さ・長さ、「動きを減らす」の扱い、押したとき・選べないとき・キーボードで選んでいるときの見た目、色の差、読み上げ、押せる広さ）を決めるのに使う。作り終えたらこのスキルで点検してから、見本と並べる。スキルの提案と見本が食い違うときは見本を優先し、食い違ったところを報告する
