# 012 支援制度と地区の行事（手入力データ）

- 主な要件：7.1（行事の項目）、7.2（行事の扱いのルール）、7.3（行事の表記）、10章（運用）、10.1（行事の集め方）、F-13
- 依存：003

## 目的

まさゆきさんが Supabase の Table Editor で入力する「支援制度」と「地区の行事」を、入力しやすく・間違えにくい形で用意する。MVP では専用の管理画面は作らない。

## 仕様メモ

### 地区の行事（`district_events`）

| 項目 | 内容 |
| --- | --- |
| 地区 | 4地区のどれか。中心市街地は元の地区名（丸山・東野・橋北・橋南）も持つ |
| 行事名 | 地区で使われている名前 |
| 季節・時期 | 春夏秋冬と「例年◯月ごろ」。日付は持たない |
| 範囲 | 地区全体／区（分館）ごと。区ごとなら画面で「区によって違います」と出す |
| 参加のしかた | 自由参加／区や組ごと／子ども向け など。事実だけ |
| 行事の絵 | 種類（祭り・運動会・文化祭など）→ 013 のドット絵 |
| 子ども向けか | 秋は子どもありなら子ども向けを優先して出す（4章） |
| 出典・確認日 | 資料名と年度、または問い合わせ先／最後に確かめた日 |
| 公開フラグ | 確認が済んだものだけ画面に出す |

- 個人名・個人の連絡先を載せない。「義務」「負担が重い」などの評価を書かない
- 目標：4地区×4季節×1〜2個＝16〜32件
- 表記：「地区の行事は、飯田市の公民館資料や地区公民館の情報をもとに独自にまとめたものです。年によって変わることがあります」＋資料名・確認日

### 支援制度（`support_programs`）

- 制度名・概要・対象の分野（移住／子育て など）・公式ページのリンク・確認日
- 「対象になります」と判定しない。必ず公式ページと窓口へつなぐ
- 月に1回、まさゆきさんが確認して確認日を更新
