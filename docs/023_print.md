# 023 印刷・PDF

- 主な要件：F-07（印刷・PDF）
- 依存：019、020

## 目的

カルテと地区くらべを、ブラウザの印刷機能で A4 縦にきれいに出せるようにする。

## 仕様メモ

- 対象：カルテ・地区くらべ。くらしの場面は MVP では対象外
- 印刷物にも出典と印刷日を入れる
- ヘッダーのボタン類・ナビは印刷しない。カードは途中で切れないようにする
- Tailwind の `print:` で印刷用のスタイルを当てる
- カルテの詳細の「現地で確かめたいこと」は、印刷すると空のチェックの箱つきで出す（2026-11-01 まさゆきさん決定）。紙を持って現地を歩き、ペンでチェックする使い方。画面のチェックはどこにも保存しない（F-02）ので、画面で押したチェックは印刷に反映しなくてよい

## 決めたこと（2026-11-09 まさゆきさん）

- **印刷するものは、使う人がチェックで選ぶ**。見出しの右上に「印刷する」ボタン（スマホ・PC の両方）を置き、押すと「印刷するものをえらぶ」窓を開く。チェックして「印刷する」を押すとブラウザの印刷を呼ぶ
- **カルテ**：一覧（`/karte`）と詳細（`/karte/<項目>`）のどちらからも同じ窓を開く。選択肢は「カルテのまとめ（一覧）」と7項目（「住まい」「子育て・学校」「交通」「防災」「人口」「公共施設」「支援制度」。並びは条件で変わるカルテの並びと同じ）。選ぶ細かさは**項目ごと**で、選んだ項目は詳細の中のタブもすべて印刷する（例：住まいは新しめ・古め・土地。借りるは家賃も）
  - 一覧から開いたときは、まとめと7項目すべてにチェックが入った状態で開く（Claude の案。実装を見て直す）。詳細から開いたときは、その項目だけにチェックが入った状態で開く
  - 1項目ずつページを分ける。中身は詳細と同じ（問い・数字・この数字から分かること・現地で確かめたいこと・数字の根拠）。「現地で確かめたいこと」は空のチェックの箱つき（画面で押したチェックは反映しない）
- **地区くらべ**：5項目（住まい・学校・交通・人口・行事）を、どれも4地区を横に並べて出す（スマホで2地区ずつ見ていても、紙は4地区）。選び方は、カルテとそろえて同じ窓で5項目から選べるようにし、最初は5項目すべてにチェックを入れて開く（Claude の案）。理由：カルテと地区くらべで「印刷する」の操作が同じになること、紙の枚数を使う人が決められること。まさゆきさんは実装を見てから決める（2026-11-09。「簡単に作れるから」で決めない）
- 印刷物には、サイト名・選んだ条件（地区・家族・家・車）・印刷日を上に、出典・対象期間・確認日を項目ごとに出す。ヘッダー・ナビ・下のタブ・ボタン・フッター・地区切りかえのパネルは印刷しない
- 見た目は 028 に合わせる（項目のアイコンや小さい絵は残す）。白黒で印刷しても読めるようにする

## 作ったもの（2026-11-09）

- 共通の部品は `src/components/print/`：`PrintControl`（「印刷する」ボタン・窓・印刷用の中身）、`PrintParts`（印刷物の上の見出し・まとまり・空の箱のチェックリスト）、`PrintMode`（印刷用の中身を作っているか）。決めごと（印刷日・選んだものの並び）は `src/lib/print/print.ts`
- カルテは `src/components/karte/KartePrint.tsx`、地区くらべは `src/components/kurabe/KurabePrint.tsx`。画面の部品をそのまま使うため、住まいのタブの中身を `HousingTabPanel`、住まい以外を `OtherTabPanel`、数字の根拠の表を `DetailBasis.tsx`、地区くらべの出典を `TopicSourceList` に切り出した
- しくみ：窓で「印刷する」を押すと、選んだものの印刷用の中身を body の直下（`[data-print-document]`）に作り、絵が届くのを待って（最大3秒）からブラウザの印刷を呼ぶ。印刷のときは中身以外を隠す（`globals.css`。`@page` は A4 縦・余白12mm）。印刷用の中身は画面には出さない
- 窓を通さずにブラウザのメニューや Ctrl+P で印刷したときは、開いているページの分を出す（カルテ一覧ならまとめ、詳細ならその項目、地区くらべは5項目すべて）
- 印刷物の上：サイト名・「わが家のカルテ」「4地区をくらべる」・選んだ条件・印刷日・この画面の URL（紙から画面に戻れるように。URL には条件しか入っていない）
- カルテ：1項目ずつ新しい紙から始める。防災と支援制度は「すべて」のタブだけを出す（種類ごとのタブは「すべて」の一部の繰り返しになるため）。施設の一覧は画面で閉じている長さでも紙では開く。支援制度は紙ではリンクを押せないので、公式ページの URL を書く。gofreely へのボタン・一覧の開け閉めの印は紙では隠す
- 「現地で確かめたいこと」の空の箱の下に、自分で書き足すための空いた行を1つ付けた（Claude の案）
- 地区くらべ：項目ごとに紙を替えず続けて並べる（紙を減らすため。5項目で4枚）。表の値は「すべての項目を一覧で見る」と同じ小さめの書き方（`compact`）
- 紙の切れ目（2026-11-09 まさゆきさん：1つの項目が2ページに分かれるのを減らしたい → 案の1と3に決定）
  - 長い一覧を含むまとまり（`PrintBlock` の `breakable`）は、印刷の直前に紙の幅（186mm）で高さを測り、1ページ（273mm）の 92% に収まるものは分けずに、入りきらなければ丸ごと次のページへ送る（`PrintControl` の `keepBlocksThatFit`、`src/lib/print/print.ts` の `fitsOnOnePage`）。92% にしたのは、画面で測る高さより紙のほうが少し高くなる（紙だけで出す URL など）ため。1ページより長いもの（防災の避難場所41か所など）は今までどおり分け、絵と大きい数字の部分は分けない
  - 見出しは、その下の中身と同じページにそろえる（タブの名前・一覧の見出し・施設の種類の見出し・出典の見出しに `break-after-avoid`）
  - 送ったまとまりの前のページの下に空白ができ、紙が増えることがある
  - 「つづき」の見出し（案の2）は、Safari で効くか分からないので作らない
- Chrome の PDF での枚数（上郷・大人2人子ども1人・買う古め・車0台）：カルテ一覧からすべて 20枚（切れ目の調整の前も20枚）、カルテの交通だけ 3枚、地区くらべ 5枚（前は4枚。項目ごとの出典が丸ごと次のページへ移るようになったため）。PDF は `~/dear-life-screenshots/2026-11-09-print/`（調整の前の版は `前の版/`）
- Safari の印刷（2026-11-09 本番でまさゆきさんが確認）：「印刷する」を押しても印刷の画面が出ず、元の画面に戻っていた。押してから絵を待つ（非同期）あいだにタップから時間がたち、Safari が印刷を受けつけなくなっていたため。印刷は押したその場で呼ぶようにし、絵は窓を開いているあいだに、チェックしているものの中身を作って先に読み込んでおく形にした
- iPhone のホーム画面のアプリ（2026-11-09 まさゆきさんの iPhone で確認）：Safari のブラウザでは印刷できるが、ホーム画面に追加したアプリで開くと印刷の画面が出ない。iOS のホーム画面のアプリで window.print() が働かない報告は iOS 9 のころからあるが、Apple の公式の説明は見つからなかった。アプリの画面には共有ボタンもないので、使う人が自分で印刷する手段もない
  - 対応（まさゆきさん決定：案1）：iPhone のアプリで開いているとき（`navigator.standalone === true`。iPhone・iPad の Safari だけの目印）だけ、印刷の窓の代わりに「Safari で開いて印刷してください」の案内を出す。「この画面の URL をコピーする」。Android・PC・Safari のブラウザは今までどおり（「Android でうまくいっているのに影響させたくない」）
  - 2026-11-09 まさゆきさんの iPhone で確認：「Safari で開く」では Safari で開けなかった。URL をコピーして Safari に貼りつければ印刷できた → 「Safari で開く」はなくし、URL のコピーと手順（コピー → Safari に貼りつけ → 「印刷する」）だけにした
  - コピーできたかが分かることが大事（まさゆきさん）：押すとボタンが「✓ コピーしました」に変わり、その下に緑の枠で「URL をコピーしました」と次にすることを出す。コピーできなかったときは、長押しでコピーできるよう URL をそのまま出す
  - 案2（別の窓で印刷用のページを開いてから印刷を呼ぶ）は作っていない。案1 で足りなければ考える
- 気をつけること：Chrome は flex の縦並びの中で紙を切ると、次のまとまりが上に重なることがある（支援制度の最後の制度と「この数字から分かること」が重なった）。印刷用の中身では flex の縦並びを使わず `space-y-*` にし、長い一覧には `print:block` を当てた。中で紙を切ってよいまとまりは `PrintBlock` の `breakable`（切らないようにすると、見出しだけの紙ができる）
