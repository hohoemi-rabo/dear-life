# 024 PWA 対応

- 主な要件：8.2（PWA 対応）、8章（個人情報）
- 依存：018、019

## 目的

スマホのホーム画面に追加してアプリのように開け、圏外でも最後に見た画面を表示できるようにする。

## 仕様メモ

| 項目 | 要件 |
| --- | --- |
| ホーム画面への追加 | 名前「DearLife 飯田移住カルテ」、短い名前「DearLife」、専用アイコンとテーマ色。アドレスバーを出さない（`display: standalone`） |
| 追加の案内 | Android は追加ボタン（`beforeinstallprompt`）。iPhone は「共有 → ホーム画面に追加」の手順を短く案内 |
| 圏外のとき | 画面の部品とドット絵は端末に保存。最後に見たくらしの場面・カルテ・地区のデータは圏外でも表示し、「オフライン表示中・データは◯月◯日時点」と出す。地図の背景は圏外では出ないことを書く |
| 更新 | つながっていれば開いたときに最新のデータを読む。画面の新しい版は次に開いたときに反映 |
| やらないこと | プッシュ通知、裏での自動同期 |
| 端末に残すもの | 公開データと、最後に見た画面の条件だけ |

- 静的書き出しなので、manifest は `app/manifest.ts`、Service Worker は自前（`public/sw.js`）か、静的書き出しに対応したライブラリを使う（依存を増やす場合はライセンス・サイズ・保守状況を確認）
- Supabase の応答はネットワーク優先・失敗時にキャッシュ。静的ファイルはキャッシュ優先＋版ごとに入れ替え
