# 031 電車の本数を出す（全国鉄道運行本数データ）

- 主な要件：F-03（カルテ）、F-05（地区くらべ）、7.1〜7.3（出典）
- 依存：026、019、029

## 目的

電車の時刻（026、市の PDF を書き写したもの）は、市の許可が出るまで公開しない。そのあいだも「何本走っているか」は出したい（2026-11-06 まさゆきさん）。
026 で確かめておいた「全国鉄道運行本数データ」の駅ごとの本数を、別の出典として公開する。時刻が公開されたら、画面は時刻から数えた本数と始発・最終に切りかわる。

## 確かめたこと（2026-11-06）

- ページ（https://gtfs-gis.jp/railway_honsu/ ）の「データのライセンスと免責事項」：「データのライセンスはCC-BY 4.0、ODbLとします」。作成・問合せ先は西澤明さん（地域・交通データ研究所代表）。データ説明資料（`20240424_document.pdf`）にはライセンスの記載はない
- どちらを選ぶかは書いていないが、クレジットに作成者・データ名・版・両方のライセンスと、手を加えたこと（駅別の発車本数を取り出した）を書けば、どちらの条件も満たす
- 対象は平日の定期列車だけ。特急など運賃のほかに料金の要る列車と、通過する列車は数えない。2026年版は 2026年3月のダイヤ（JR東海は「JTB時刻表 2026年3月」から数えた）
- 4地区の駅の発車本数は、026 で市の時刻表から数えた本数と同じ（伊那上郷 上り20・下り18、桜町 上り20・下り18、ほかの5駅は上り19・下り19。どれも合計38本）

## 決めたこと（2026-11-06）

- **本数を時刻の許可を待たずに出す**（まさゆきさん決定）。026 では「確かめ用と、許可が出なかったときの代わり」としていた
- **地図（028）の前にやる**（まさゆきさん決定）
- 「駅の発車本数」を使う（着く本数は数えない）。026 の「駅を出る電車」と同じ数え方
- 表には飯田線の駅をすべて入れ、どの地区の駅かは `screen_data()` が 026 の駅（`facilities`）と駅名で結びつけて決める。地区の振り分けを2か所に持たないため
- 画面は時刻が公開されていればそちら（1日・始発・最終）、なければ運行本数データ（平日）を出す（`src/lib/karte/train.ts` の `trainTrips`）。運行本数データのときは「平日」と添え、始発・最終の列は出さない
- 地区でいちばん本数の多い駅を大きく出す。いちばん多い駅が2つ以上（鼎・中心市街地は3駅とも38本）なら、駅名ではなく「各駅」（カルテ）・「3駅とも」（地区くらべ）と出す。並びで最初の駅だけを出すと、その駅が地区の代表に見えるため
- 地区くらべの行は見本にないが、まさゆきさんの依頼で足した（交通のタブの「駅」のすぐ下、一覧は「電車」のまとまり）
- くらしの電車のピンのシートには、まだ本数を出していない（場面の電車の便は時刻のデータなので、許可が出るまで「データ未取得」のまま）
