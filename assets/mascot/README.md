# マスコットの動きの元（042）

まさゆきさんが生成AIで作ったマスコットのアニメーション。画面にはそのまま出さず、`npm run mascot` が背景を消してコマを横に1列に並べた WebP（`public/mascot/`）を作る。差しかえるときは同じ名前で置きかえて流し直す。一覧は `src/lib/mascot/assets.ts`。

用意するときの決まり（042 の「決めたこと」）：背景はマゼンタ（#FF00FF）の単色（なければ緑。2026-11-15 から。クリーム色・白っぽい背景は頭のてっぺんと見分けられず欠ける）、エプロンは見本の青緑、エプロンのほかに青緑・青を使わない、最後のコマが最初につながるループ。MP4 ではなく GIF にする（360×640 くらい、1秒8〜12コマ）。マゼンタ・緑の背景の GIF は、`MASCOT_SOURCES` で `key` を付ける。下の表のいまの GIF は、白っぽい背景のもの。
