# 034 家賃の参考値と、地区の借家の世帯数（e-Stat）

- 主な要件：2.3（MVPに入れないもの。2026-11-08 改訂）、4章（家：借りる）、5章（相場の表示ルール）、7章、F-05（地区くらべ）
- 依存：011（国勢調査の小地域集計の取り込み）、019・028（カルテの住まい）、029（地区くらべ）

## 目的

「借りる」を選んだ人に、今は「家賃の情報はまだありません」としか出せていない。不動産情報ライブラリには家賃がない（売買の取引だけ）ので、国の統計から次の2つを取り込み、MVP に入れる（2026-11-08 まさゆきさん決定。023 より先に着手）。

1. **家賃の参考値**：総務省「令和5年住宅・土地統計調査」の、飯田市の民営借家の1か月あたりの家賃の平均（飯田市全体の値。4地区には分けられない）
2. **地区の借家の世帯数**：総務省「令和2年国勢調査 小地域集計」の、持ち家・民営借家に住む一般世帯の数（町丁・字等ごと → 4地区に合計）

## 調べた結果（2026-11-08）

### 住宅・土地統計調査（家賃）

- 表：「令和5年住宅・土地統計調査 住宅及び世帯に関する基本集計」表130-2「民営借家＜専用住宅＞の状況 住宅の建て方(5区分)、延べ面積(6区分)別住宅の１か月当たり家賃」（統計表ID `0004021532`）。全国・都道府県・市区町村。調査は 2023年10月
- 飯田市：家賃0円を含む 49,099円、含まない 50,043円（建て方・延べ面積とも総数）。e-Stat のデータを載せた第三者のサイト（ecitizen.jp）で読んだ値なので、取り込みのときに e-Stat の元の表で確かめ直す
- 建て方（一戸建・長屋建・共同住宅など）× 延べ面積でも分かれている。抽出の調査からの推計なので、細かく分けると値がぶれたり空欄になったりしうる。どこまで出すかは実際の値を見て決める
- 平均値（真ん中の値ではない）。5年に1回（次は令和10年調査）
- 市区町村の表は e-Stat のデータベースにしかない見込み。API はアプリケーションID（無料の利用登録）がいる。手元のスクリプトで取るか、CSV を手で落とすかを決める
- 利用条件：政府標準利用規約（第2.0版）。出典の表示がいる。飯田市のオープンデータではないので市の了承はいらない

### 国勢調査 小地域集計（借家の世帯数）

- 011 と同じ取り方（統計GISの「統計データダウンロード」、長野県の ZIP、Shift_JIS の CSV、API キーなし）で取れる
  - `T001085`：住宅に住む一般世帯／持ち家／民営借家（公営・社宅・間借りの欄はなく、総数から2つを引いた残りに入る）
  - `T001086`：主世帯／一戸建／長屋建／共同住宅（1・2階建、3〜5階建、6〜10階建、11階建以上）／その他
- 伏せられた町丁（X）は数か所で、どれも同じ地区の隣の町丁に合算されている（東栄町・松尾町・銀座・大休・横手）。4地区の合計には影響しない見込み（取り込みで 011 と同じく確かめる）
- 手で合計した概算（2020-10-01。中心市街地は「宮の上」を対応表の「宮ノ上」として足した値。正しい値は取り込みのスクリプトで出す）：

| 地区 | 住宅に住む一般世帯 | 民営借家 | 割合 |
|---|---|---|---|
| 上郷 | 5,550 | 1,697 | 30.6% |
| 鼎 | 5,292 | 1,511 | 28.6% |
| 中心市街地 | 約5,653 | 約1,517 | 約26.8% |
| 伊賀良 | 4,969 | 1,062 | 21.4% |

## 仕様メモ

- 点数化・ランキング・おすすめはしない。借家の割合を「借りやすさ」のように言いかえない。世帯の数と割合を事実として出す
- 家賃は「飯田市全体の平均」「調査の年」「地区ごとの値ではない」「今の募集家賃ではない」ことを必ず添える
- 出典・対象時点・確認日を出す。取れなかったら「データ未取得」（F-09）
- 更新は手動（住宅・土地統計調査は5年ごと、国勢調査も5年ごと）

## Claude が決めたこと（2026-11-08。見てもらう）

- 家賃は「家賃0円を含まない」平均を使う。0円の借家（親族の家など）は、これから借りる人の参考にならないため（含む値は 49,099円、含まない値は 50,043円）
- 延べ面積では分けない（総数だけ）。面積で分けると推計の元が少なくなり、一戸建・29㎡以下が 15,000円のように値がぶれるため
- 建て方は一戸建・共同住宅（木造）・共同住宅（木造以外）の3つ。長屋建・その他は出さない（その他は値なし）。名前は統計の言い方のまま（「アパート」「マンション」と言いかえない）
- 家賃は推計値なので「約5.0万円」のように万円の小数1桁で出す（円の位までは出さない）
- 世帯の割合は「住宅に住む一般世帯のうち、民営の借家に住む世帯」の整数の%。公営の借家・社宅は入れない（表に欄がない）
- 断り書き：「飯田市全体の平均で、地区ごとの値ではありません。今募集している物件の家賃でもありません。」（`RENT_NOTICE`）
- カルテの住まいの「借りる」のボタンは「家賃の内訳を見る」、くらしのシートのボタンは「住まいの家賃を確かめる」にした。確認メモの問いは「家賃の目安と、住む前の確認点は？」にした（前は「値段の目安と、住む前の確認点は？」）
- 地区くらべの住まいのタブには「民営の借家に住む世帯」の行を足した。タブの見出し「住まいの相場」と注意書き（過去の取引の参考値）はそのまま

## 更新の手順（5年ごと・手動）

1. 新しい住宅・土地統計調査（次は令和10年調査）の市区町村の表が e-Stat に出たら、`src/lib/housing/import.ts` の `RENT_SURVEY_NAME`・`RENT_STATS_DATA_ID`・`RENT_AS_OF` を差しかえる。表の分類（建て方・延べ面積・家賃0円を含む／含まない）の番号が変わっていないか `getMetaInfo` で確かめる
2. 新しい国勢調査の小地域集計が出たら、`TENURE_CENSUS_NAME`・`TENURE_DOWNLOAD_URL`（「住宅の所有の関係別一般世帯数」の statsId）・`TENURE_AS_OF` を差しかえる（人口の 011 と同じ時期）
3. `npm run rent:sql` を動かす。対応表にない町丁・字等で止まったら `data/iida_district_map.csv` に足して `npm run town-map:sql` で当ててから、もう一度動かす
4. `npm test` を通し、Supabase MCP の `apply_migration` で当てて、ファイル名の版番号を `list_migrations` に合わせる
