## 目的

アクセスしたときの入口（`/`）が、文字とボタンだけで地味。見本のように、大きな絵・「風景はイメージ、数字は公開データ」の帯・01〜03 の流れ・4地区のカードを並べて、ゲーム感覚のワクワク感と「データは本物」を最初に伝え、押したくなる入口にする（2026-11-07 まさゆきさん）。

## 決めたこと（2026-11-07 まさゆきさん）

- **大きな絵は1枚で、季節では替えない**。見本の「春・夏・秋・冬」のタブの位置には、**押せない文字だけの札「春夏秋冬を のぞける」** を置く（ボタンに見えない形にする）
- **4地区のカードを押すと、その地区を選んだ状態で `/erabu` から始める**（URL の `d`）
- **「前に見た暮らしのつづきから」は、初めての人には出さない**。今と同じく、前に見た画面があるときだけ出す（`ResumeLastView`）。見た目は見本の文字のリンクにする
- **まず PC だけで確認する**。スマホの形はそのあと
- **上のメニュー（ヘッダー）は今のまま**。見本の「えらぶ → くらしを見る → カルテ」「データについて」は、今のヘッダーの進みぐあいとリンクのまま変えない
- **トップのヘッダーには進みぐあい（えらぶ → くらしを見る → カルテ）を出さない**。まだどのステップでもないため。「データについて」は出す（2026-11-07 まさゆきさん。`HeaderNav`）

## 案

- 絵は今までどおり `npm run illust` で WebP にする。`top-icons.png` は決まった位置で7つに切り分ける
- ページ `src/app/page.tsx` は Server Component のまま組み、`ResumeLastView` だけをクライアントにする（今と同じ）
- 部品は `src/components/top/` に置く
- 地区のカードの行き先は `src/lib/conditions/url.ts` で作る（えらぶの最初の質問で、その地区が選ばれた状態）

## 作ったもの（2026-11-07）

- ページは `src/app/page.tsx`、部品は `src/components/top/`（`TopHero`・`TopNotes`・`TopSteps`・`TopDistricts`・`TopIcon`）。地区のカードの行き先は `src/lib/top/links.ts` の `erabuHrefFor`（`/erabu?d=<地区>`。えらぶは地区の質問が開き、その地区が選ばれている）
- 見出しの下の黄色い線は Tailwind の色 `marker`
- `top-icons.png` は `npm run illust` が透明度 96 より薄いところを消し（`FAINT_NOISE_ALPHA`）、7つに切り分けて `top-<名前>-128/256.webp` を書く
- 地区のカードの絵は、PC の高解像度の画面でぼやけないよう `district-*` の書き出しに 960px を足した（えらぶ 01 も同じ絵を使う）
- 「前に見た暮らしのつづきから」は `ResumeLastView` を文字のリンクにした（読み上げでは戻る先の画面の名前も伝える）
- 見本のいちばん下の一行は、全画面共通のフッター（`SiteFooter`）のままにする（2026-11-07 まさゆきさん OK）
- 「＼ゲーム感覚で、飯田の暮らしを体験／」は、文字の大きさはそのままで、見出しの1行目「もしも、わが家が」の上の真ん中に置く（2行目は「。」と黄色い線のぶん長いので、真ん中の計算に入れない。2026-11-07 まさゆきさん）
- PC の大きな絵は、右に花の飾りの幅（`lg:pr-16`）を空けて花と重ねない。左の列は見出しの2行目が収まる幅（30rem）。見本では花が画面の右端まで出ているが、横にスクロールしないよう中身の範囲に収めた（2026-11-07 まさゆきさん OK）
