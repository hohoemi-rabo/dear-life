# 018 02 くらしを見る 画面

- 主な要件：F-11（季節の切り替え）、F-12（場面の表示）、F-13（行事の表示）、F-14（答え合わせへの移動）、F-04（地区の切り替え）、6章、11.1（想定の文の見せ方）
- 依存：013、016、017

## 目的

選んだ条件で過ごす春夏秋冬の場面を、ドット絵と文章と地区の行事で見せる。サービスの顔になる画面。

## 仕様メモ

- 春・夏・秋・冬のボタンで好きな順に見られる。最初は春。ランダムにしない
- 1季節1場面：ドット絵1枚（背景＋地区の目印＋家族＋行事を重ねる）＋3〜5文＋出典
- 文の種類で見た目を区別する：データ＝出典の印、地区の情報＝確認日、想定＝色や印（デザインイメージでは「想定」のバッジ）。見せ方は作りながら提案する
- 行事は選んだ地区の、その季節の行事を1〜2個。未収集なら「この季節の行事は準備中です」。区ごとの行事は「区によって違います」。秋・子どもありは子ども向けを優先
- 「カルテで確かめる」ボタンはどの季節からでも出す。場面の中のデータ（保育園の数、避難場所など）からカルテの該当カードに直接移れる
- 地区をこの画面のまま切り替えられる。家族などの条件チップと「選び直す」も出す
- 出典・確認日は「出典・確認日を見る」で開ける
- PC：デザインイメージ PC版のように、左に「わが家の設定」、中央に場面、右に「この季節の地区の行事」と「暮らしの根拠を確認」、下に4季節のサムネイル
- 行事の注意書き「年によって変わることがあります」を出す
- 冬・車0台の場面では、実際の便（時刻・本数）を会話ウィンドウ風の枠に出典つきで出し、「この便を gofreely で調べる」ボタンを置く（要件 1.1・6.3）。gofreely に何を渡すかは両方の実装を見て決める
- 季節は URL に持つか（例：`s=spring`）検討する（戻る操作・共有に強い）

## 決めたこと（2026-10-27）

- 文の種類の見せ方（提案）：**データ**＝文のあとに緑の「出典1」の印（番号は「出典・確認日を見る」の番号）／**地区の情報**＝茶色の「地区の情報・確認日 ◯年◯月◯日」の印／**想定**＝灰色の文字と灰色の「想定」の印。場面の下に3つの印の凡例を出す。値が出せない文の知らせ（「◯◯：データ未取得」など）は「―」を付けた灰色の小さい文字
- 場面の文章は会話ウィンドウ風の枠（`pixel-frame`）に、ふつうのフォントで出す（要件 8.1）。行事・設定の欄は実データの側の `Card`
- カルテへのリンクは、文ごとではなく場面に出てきたカードごとに1つ（「子育て・学校をカルテで確認 →」）。知らせの行のカードも含める
- いつの時刻表か：バスは「2027年1月16日（土）の時刻表」、電車は出典の対象（「2026年3月14日改正のダイヤ」）を、それぞれ最初の文の下に1回だけ出す
- 絵の組み方（`src/lib/kurashi/picture.ts`）：背景 → 地区の目印 → 田畑の左（その季節の行事1つ目）→ 田畑の右（春・子どもあり＝学校、春・子どもなし＝公共施設、夏＝避難場所、秋＝行事2つ目、冬・車0台＝駅のある地区だけ電車）→ 家族 → 道の右（冬＝車かバス）→ 夏は大雨。その季節の行事がなければ行事の絵は出さない（ない行事を絵で作らない）
- ひな形が公開されていない季節も、絵と行事は出し、文章は「この季節の場面の文章は準備中です。」（今の本番はこの表示）
- 場面の見出しは場面の軸ごとに固定（`SCENE_AXIS_LABELS`。春｜入園・入学の季節、夏｜大雨と避難 など）
- 地区くらべ・地図へのリンクは、その画面ができてから足す（020・021）。デザインイメージの「モックアップ」は出さない

## 測った値（2026-10-27）

静的書き出しを gzip つきで手元から配り、Chrome の回線の制限（往復150ms・1.6Mbps、015 と同じ目安）で、鼎・冬・車0台を開いた（Supabase の応答は本番の未公開データ＋下書きのひな形を、0.65秒待たせて返した）。

| | CPU そのまま | CPU 4倍遅く |
| --- | --- | --- |
| 見出し | 1.5秒 | 2.7秒 |
| 場面の文章 | 2.3秒 | 3.7秒 |
| 絵（PNG）まで全部 | 4.7秒 | 5.2秒 |

- 絵の PNG は全部で 2KB だが、場面の文章が出た時点で日本語フォント（Noto Sans JP）の文字の範囲ごとのファイルが28個・670KB 読み込まれ、回線をほぼ使い切るので後ろに回る。絵を `priority` で先に読ませても変わらなかった（画像はデータが届いてから描くため）。文字はフォントを待たずに端末の文字で出る（`display: swap`）
- 軽くするなら、本文を端末の日本語フォント（iPhone はヒラギノ、Android は Noto Sans CJK）にして Web フォントをやめる、またはロゴ・見出しだけに使う、が候補。全画面に効くので 002 の決めごととしてまさゆきさんに決めてもらう
