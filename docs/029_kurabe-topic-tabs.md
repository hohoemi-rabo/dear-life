- 見本：`docs/design/kurabe-pc.png`（PC）、`docs/design/kurabe-mobile.png`（スマホ）。どちらも「住まい」を選んだ状態

## 目的

今の比較表のよさを生かしたまま、長い一覧を読み続ける負担を減らす（2026-11-05 まさゆきさんの提案）。

- 項目をタブで分け、一度に読む情報を絞る
- 数字を大きく、横一列にそろえる
- 選んだ地区の列を薄く強調する
- 出典は開いて確認する
- 全体を見たい人のために「すべての項目を一覧で見る」を残す

## 決めたこと（2026-11-05）

- **土地の幅は最初から見せる**（まさゆきさん決定）。見本の「価格の幅を見る」の場所に「幅 0.51万円〜2万円」と1行で出す。要件 5.1「幅の表示を省略しない」を守るため
- **土地には「200m²（約60坪）なら 約○万円」も出す**（まさゆきさん決定）。㎡単価だけでは土地全体の値段が分かりにくいため。見本にはない行で、要件 5章-4 の目安。坪単価はカルテの詳細に任せる。スマホのタブの中にも出す。PC の一覧の表にはまだ入れていない
- **スマホは2地区を左右に並べる**（2026-11-06 まさゆきさんの見本）。左は選んだ地区で固定し、右の比べる地区を変える。地区名の欄はスクロール中も上に固定する
- 決まりごとに合わせて見本と変えたところ：「中央値」→「真ん中の値」（要件 5章-7）、「件数少なめ」→「件数少なめ・参考程度」（要件 5章-6）、ロゴの下は「飯田移住カルテ」のまま（サイト名・ロゴに飯田市の名称を使わない。要件 7.3）
- 出典の欄の右に出す名前は、出典の `publisher` をそのまま出す（見本の表記は「国土交通省「不動産情報ライブラリ」」、画面は「国土交通省 不動産情報ライブラリ」）。出どころが複数なら「ほか」を付ける
- 見本にないタブの中身は住まいと同じ形にする。項目は 020 の項目を分けただけで、増減はない
- タブは URL の `t`（`housing`・`school`・`transport`・`population`・`events`、一覧は `all`）。知らない値と値なしは「住まい」。タブを押しても履歴は増やさず、位置も変えない（くらしの季節と同じ）
- 最後のタブの帯は最初のタブへ戻す
- 地区を選んでいないときは列の強調をせず、「わが家のカルテ」「○○のカルテに戻る」を出さない。代わりに「地区をえらんで、くらしを見る」を出す
- タブのアイコンは見本どおり線の絵（`KurabeIcon`）。ライブラリは増やさない
- 「くらしを見る」のリンクは見本にないので外した（上のメニューから行ける）
- 「比べる」の表記は見本のまま。見出しの「4地区をくらべる」も見本のまま

- スマホで見本と変えたところ：「過去の取引の中央値」→「過去の取引の真ん中の値」、「件数少なめ」→「件数少なめ・参考程度」、「価格の幅を見る」→ 幅と 200m² の目安をそのまま出す（PC と同じ決定）
- 比較相手は URL の `v`（地区の id。`all` は4地区の一覧）。最初の相手は、地区の並びで最初の別の地区（上郷なら鼎）。おすすめに見えないよう、機械的に決める
- 地区を選んでいないときは2地区にできないので、切りかえを出さず4地区の一覧だけを出す
- 「4地区を一覧」はタブを残したまま、そのタブの項目を4地区で縦に並べる。URL で `t=all`（PC の全項目の一覧）を開いたときだけ、スマホにも全項目と「項目を切りかえて見る」を出す
- スマホの見本にないので、「地図で場所を見る」のボタン・次のタブへの帯の文・進みぐあいは、地区くらべのスマホでは出さない。スマホのメニューには地図もくらしもないので、地図とくらしへはカルテを経由して行く（2026-11-06 まさゆきさん決定）
- 注意書きは、スマホでは見本どおり「現在の売り出し価格ではなく、過去の取引の参考値です。」の1文だけにする
