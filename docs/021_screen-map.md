# 021 05 地図 画面（MapLibre）

- 主な要件：F-06（地図）、7章（背景地図）、7.2（学区の扱い）、8章（地図の位置は目安）、8.2（圏外では背景が出ない）
- 依存：008、009、015

## 目的

学校・保育・バス停・避難場所の位置関係と小学校区の範囲を地図で確かめられる画面を作る。

## 仕様メモ

- MapLibre GL JS（無料）で表示。下地は国土地理院の地理院タイル（標準地図・航空写真）、立体は標高タイル。代替は OpenStreetMap
- 最初は真上から見た平面。「立体で見る」で地図を斜めに倒し、山の起伏をつける。立体では下地を航空写真にもできる。動きが重い機種のために平面に戻せる
- 種類ごとに表示・非表示（学校・保育・バス停・避難場所）。点をタップすると名称・住所・出典
- 小学校区は面で表示。距離は表示しない
  - `school_districts` には市全体の学区が入っている（4地区の外の学校の学区は `district_id` が null。008）。`geometry` は API がタイルの境目で切った切れ端を並べた MultiPolygon なので、輪郭の線をそのまま引くとタイルの境目にも線が出る。面の塗りだけにするか、画面側でつなぎ直す（例：turf の union）
- 「地図の位置は目安です」と書く。地理院タイルの出典表記を地図上に出す
- 「いいだWebまっぷ」へのリンク（データは取り込まない）を検討する
- MapLibre はサイズが大きいので、この画面だけで遅延読み込みする（`next/dynamic` + `ssr: false`）
- 地理院タイルの利用条件（出典表記・商用利用）を確認する

## 決めたこと（2026-10-27）

- ルートは `/chizu`。地区（URL の `d`）を選んでいればその地区へ、選んでいなければ4地区が入る範囲で開く。地図の上の4地区のボタンで切り替える（URL の `d` も変わる）。地区の境界の線は持っていないので、場所を合わせるだけ
- 点は4地区ぶんをすべて出す（選んだ地区だけにはしない。地区の境目の近くの施設も見えるように）。種類は 学校・保育園・幼稚園など・放課後児童クラブ・バス停・駅・避難場所 と小学校区。最初は 学校・保育・バス停・駅・小学校区 を出し、避難場所（155か所）と放課後児童クラブは切り替えで出す。切り替えの横に「4地区でNか所」「該当なし」「データ未取得」を出す（件数を並べるだけ）
- 点の色は種類を見分けるためだけに使う（`POINT_STYLES`）。小学校区は学校ごとに色を変え、凡例に学校名を出す
- 点をタップすると、名称・区分・住所（なければ「出典に記載なし」）・地区・出典を、地図の下（PC は右）に出す。指で押しやすいよう、タップした所から 22px 以内でいちばん近い点を選ぶ。点がなければ小学校区（学校名と「学区は年度で変わる」の注意書き）
- 地図を使えない人・端末のために「一覧で見る」を付け、選んだ地区（なければ4地区）の表示中の種類の施設を並べる。押すと地図のタップと同じ詳細を出す
- 小学校区はタイルの境目で切れた切れ端なので、画面側でつなぎ直して輪郭を引く。つなげられないときは切れ端のまま面だけ塗る（境目の線を出さない）
- 立体：地図を 60度倒し、標高タイルで起伏（1.5倍）と陰影をつける。下地の「地図・航空写真」は立体のときだけ選べ、「平面に戻す」で標高の計算をやめて地図の下地に戻す
- 動かせる範囲は飯田市のまわり（`MAX_BOUNDS`）、ズームは9〜18
- 地理院タイル（2026-10-27 にタイル一覧のページで確認）：ウェブでリアルタイムに読み込むなら出典の明示だけで申請は要らない。出典は「地理院タイル」と書き、タイル一覧のページへリンクする（地図の右下と、出典の欄）。国土地理院コンテンツ利用規約は PDL1.0 で商用も可
  - 標準地図はズーム5〜8だと GEBCO などの出所も要るので、ズーム9より引けないようにした
  - 航空写真（全国最新写真）はズーム9〜13が全国ランドサットモザイク画像なので、タイル一覧の指定どおりの Landsat8 の出所も書く。GRUS 画像（© Axelspace）は北緯20度付近だけなので書かない
  - 標高は DEM10B の PNG（`dem_png`）。高さ = (R×2^16 + G×2^8 + B)×0.01 を MapLibre の `encoding: "custom"` で読む。負の値・値なしの扱いは飯田では起きないので省いた
- 注意書きは「地図の位置は目安です。」と「圏外では背景の地図が出ません。」（要件 8.2。`NOTICES.mapOffline` を足した）
