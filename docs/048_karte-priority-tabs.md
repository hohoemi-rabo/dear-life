# 048 カルテのタブを、選んだ項目のカードを出す切りかえにする（大切にしたいこととの紐づけ）

- 主な要件：4章（選択の反映ルール）、F-03（カルテ表示）、8章（タップ領域）
- 依存：014（並びのルール `karteLayout`）、016（えらぶ 05 大切なこと）、019・028（カルテ一覧）、036（下見プラン）、023（印刷）

## 目的

2026-11-20 まさゆきさん：えらぶの「大切にしたいこと」とカルテを、しっかり紐づけたい。タブを選んだら、その項目のカードを出す形にし、「すべて」のタブも用意する。

## いまの作り（2026-11-20 本番で確かめた）

- カルテ一覧（`/karte`）は、7つのカードがいつも全部並ぶ。タブ（`KarteTabs`、`src/components/karte/KarteEntries.tsx`）は押すとそのカードまで画面が動く目次で、表示は切りかわらない。開いたときは先頭のタブが緑になるが、「表示中」の意味はない
- 並び（`karteLayout`、`src/lib/conditions/karte-order.ts`）は、大切にしたいこと → 子ども1人以上なら子育て・学校 → 車0台なら交通 → 残り → 支援制度。タブもカードもこの順
- ずれ：大きいカード（住まい・子育て・学校・交通・防災）と小さい1行のカード（人口・公共施設・支援制度）を別の列に分けている（`splitKarteCards`）。そのため、人口を選ぶとタブは先頭に来るが、人口のカードは下のまま
  - 例（上郷・子ども1人・車1台・人口を選ぶ）：タブ「人口 → 子育て・学校 → 住まい → …」、カード「子育て・学校 → 住まい → 交通 → 防災 → 人口 → …」

## 決めたこと（2026-11-20 まさゆきさん）

- タブは、表示を切りかえるものにする。押すと、そのタブのカードを出す
- タブの並び：
  - 大切にしたいことを1つ以上選んだとき：`わが家の大切なこと｜すべて｜（項目7つ、karteLayout の順）`
  - 何も選ばなかったとき：`すべて｜（項目7つ）`（「わが家の大切なこと」は出さない）
- 開いたときに選ばれているタブ：
  - 大切にしたいことを選んだとき：「わが家の大切なこと」。選んだ項目のカードを**全部**出す（2つ選べば2枚。選んだ順＝karteLayout の順）
  - 何も選ばなかったとき：「すべて」
- 「すべて」：今と同じく7つのカードを全部並べる
- 項目ごとのタブ：選ばなかった項目も含めて7つとも残す。押すとその項目のカード1枚を出す。人口・公共施設・支援制度は1行の小さいカードを1枚出す
- 「わが家の大切なこと」のカードの下に、選ばなかった項目に気づける案内（例：「ほかの項目も見る」→「すべて」に切りかえる）を置く。選んだカードだけで終わりにしない（選ばなかった項目にも確かめることがあるため）
- 人口を選んだときも、「わが家の大切なこと」で人口のカードが出る（上のずれをなくす）

## 作るときの注意

- 見本（`docs/design/karte-mobile.png`・`karte-pc.png`）はタブの下にカードが全部並ぶ形。「すべて」タブがその見本の形になるので、見本の要素はなくさない
- 要件 4章の「大切にしたいこと」の行に「選ばなかった分野も非表示にはしない」とある。この変更で、開いたときは選んだ分野だけを出すので、要件を直す（選ばなかった分野も、項目ごとのタブと「すべて」で必ず見られる、と書く）。F-03 も合わせて直す
- カルテの上の一文（「○○に関する情報を先に表示しています」など、`leads`）は残す。開いたときの表示に合うよう、言い回しを見直す（例：「先に表示」→「わが家の大切なことに表示」）。文言はまさゆきさんに見せる
- カードへ移るリンク（`#karte-<項目>`）を使っている所がある：「わが家の確認ポイント」（`CheckMemo`）、下見プラン（`ShitamiMemo`）など。`#` で来たときは、そのカードが出るタブ（その項目のタブ）に切りかえてから移る
- 印刷（023 `KartePrint`）は、タブに関係なく今までどおり選んだものを印刷する
- 地区を切りかえたときの強調（`useDistrictSwitch` の `cardsHighlighted`）は、表示中のカードにだけかかる
- タブは `role="tablist"`・`role="tab"`・`aria-selected`・`aria-controls` にし、矢印キーで移れるようにする。タップ領域は 44px 以上
- 地区くらべ（`/kurabe`）・くらし・詳細のページは変えない
- テスト：開いたときのタブ（選んだ／選ばない）、「わが家の大切なこと」に選んだカードが全部出ること（人口を含む）、項目のタブで1枚だけ出ること、「すべて」で7枚、`#` で来たときの切りかえ、URL のタブの値が知らない値のとき

## 作ったもの（2026-11-20）

- タブの決めごと（並び・開いたときのタブ・出すカード・URL の `tab` の読み書き・`#karte-<項目>` の読み取り）は `src/lib/karte/tabs.ts`。URL の項目の名前は詳細のページと同じ（`tab=public-facilities`）
- タブは `KarteTabs`（`src/components/karte/KarteEntries.tsx`）。`role="tablist"`・`role="tab"`・`aria-selected`・`aria-controls`、←→・Home・End で移る。PC（xl）は上の段に「わが家の大切なこと」「すべて」、下の段に7項目の格子。スマホ・iPad は1行で横に流し、URL の `tab` で右の方のタブから開いたときは、選んだタブが見える位置まで列を送る
- 今のタブは `KarteView` の `useKarteTab`。押すと `router.replace` で `tab` を書きかえる（履歴を増やさない）。「ほかの項目も見る →」は「わが家の大切なこと」のカードの下にだけ出し、押すと「すべて」に切りかえる
- 一覧のカード（`KarteEntries`）は今のタブのカードだけを出す。大きいカードがなければ上の列、小さいカードがなければ下の列を出さない
- 詳細のページへ移るリンクと、詳細のページの「一覧に戻る」は `tab` を持ち回る（`src/lib/karte/links.ts`）。詳細から戻ったときに、見ていたタブで開くため
- 上部の一文は `karteLayout` の `leads` を「○○を「わが家の大切なこと」にまとめています。」の1文だけにした（印刷も同じ）
- `#karte-<項目>` で来たときはその項目のタブに切りかえてから移る。なお、調べたところ「わが家の確認ポイント」と下見プランは `#karte-…` ではなく詳細のページ・`#shitami-memo` へ移っていたので、変える所はなかった
- タブを押したら、カードの枠を約0.3秒でふわっと出す（下から12px・透明から。2026-11-20 まさゆきさん。`KarteView` の `useTabFadeIn`）。中身を作り直すとデータの読み込みやカードへ移る動きがやり直しになるので、枠に Web Animations をかける。開いたときと「動きを減らす」の設定では動かさない
- 画面写真：`~/dear-life-screenshots/2026-11-20-048-impl/`（`mobile-*`・`pc-*`・`ipad-chosen`。上郷・子ども1人・車1台・防災と人口を選んだとき、`-all`・`-transport`・`-population-only`、何も選ばない `-none`、見出しの一文 `-lead`）。タブの高さは 44px、横のはみ出しはなし
