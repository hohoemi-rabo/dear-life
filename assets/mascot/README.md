# マスコットの動きの元（042）

まさゆきさんが生成AIで作ったマスコットのアニメーション。画面にはそのまま出さず、`npm run mascot` が背景を消してコマを横に1列に並べた WebP（`public/mascot/`）を作る。差しかえるときは同じ名前で置きかえて流し直す。一覧は `src/lib/mascot/assets.ts`。

用意するときの決まり（042 の「決めたこと」）：背景は白に近い単色か透明（体と同じクリーム色はだめ）、エプロンは見本の青緑、エプロンのほかに青緑・青を使わない、最後のコマが最初につながるループ。

| ファイル | 使う場所 | 中身 |
| --- | --- | --- |
| `kamisato-sweep.gif` | くらし・上郷の4季節（右上の石段の中ほど） | ほうきで掃く。480×480・58コマ・1コマ80ミリ秒（約4.6秒）。背景は5色だけのクリーム色で、頭のてっぺんの明るいところとほとんど同じ色。ほうきの先まで絵の中に入っている（2026-11-15 に、ほうきの先が切れていた最初の版から差しかえ。元は `mascot_sweep_flat_loop.gif`） |
