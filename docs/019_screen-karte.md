# 019 03 カルテ 画面

- 主な要件：F-03（カルテ表示）、F-04（地区の切り替え）、4章（カルテへの反映）、5章（相場の表示）、7.2、F-09
- 依存：015、018

## 目的

場面の根拠を分野ごとのカードで確かめる「答え合わせ」の画面を作る。v1.0 の「02 移住カルテ」と同じ役割。

## 仕様メモ

- 上部：選んだ条件（地区・家族・家・車）と「条件を変える」、地区の切り替え
- 条件がどう反映されたかを上部の一文で必ず伝える（例：「子育ての情報を先に表示しています」）
- カードの並びは 014 の関数で決める。既定：住まい → 子育て・学校 → 交通 → 防災 → 人口 → 支援制度
- 各カードに出典と対象時点（確認日）を付ける。「該当なし」と「データ未取得」を区別する

| カード | 中身 |
| --- | --- |
| 住まい | 土地の真ん中の値・幅・件数・坪単価・「200㎡なら約○万円」、中古戸建て（築20年以内／21年以上）の真ん中の値・件数・件数ラベル。「借りる」なら「家賃の情報はまだありません」を出し、売買の参考相場は「参考に見る」で開く。伊賀良は幅の表示を省略しない |
| 子育て・学校 | 主な学区（学校名）、学校・保育施設の数と一覧。「入学前に市で確認を」。学校は市の教育機関一覧（`source_id = 'iida_education'`）、保育施設は市の子育て施設（`source_id = 'iida_childcare'`、`kind = 'childcare'`）、放課後児童クラブ（`kind = 'after_school_club'`）は保育施設と数を分けて出す（009） |
| 交通 | バス停の数（駅があれば駅も。026 の案：駅ごとに上り（豊橋方面）・下り（辰野方面）の1日の本数と始発・最終を `train_departures` から数えて出す。伊賀良は「地区内に駅はありません」）。車0台なら注意書きと、場面で使った便・乗り場の1日の本数、gofreely へのリンク（018 の `gofreelyHref`） |
| 防災 | 避難場所の数と一覧 |
| 人口 | 人口と年齢構成・対象時点 |
| 支援制度 | 制度名・概要・公式リンク。「対象になります」と判定しない。公式で確認の注意書き |

- 相場は「真ん中の値」と書き、件数・件数ラベル・「過去の取引の参考値」の注意書きを必ず付ける
- くらしの場面から来たときは該当カードまでスクロールして開く（アンカー）
- 下部：地区くらべ・地図へのボタン、「くらしに戻る」

## 決めたこと（2026-10-27）

- 公共施設のカード：id は `public_facilities`、表示名は「公共施設」（`karte_card` の enum にも足した）。既定の並びは 住まい → 子育て・学校 → 交通 → 防災 → 人口 → **公共施設** → 支援制度。大切にしたいことの選択肢には入れない（えらぶ画面は 016 で了承をもらったまま）。子ども0人のときは 公共施設 → 子育て・学校 → 支援制度 の順になる
- カードは開け閉めできる（`<details>`）。最初は1枚目だけ開き、場面から来たときはそのカードも開く。件数の多い一覧（バス停・学校・避難場所など）は、数を大きく出して一覧は「◯◯の一覧を見る」で開く
- 住まい：選んだ家に近い相場を先に大きく出す（新しめ＝築20年以内、古め＝築21年以上）。土地は ㎡ の真ん中の値・幅（下位25%〜上位25%）・坪単価・「200㎡（約60坪）なら約○万円」。件数ラベルは `countLabel` のまま（えらぶ画面の「新しめは必ず件数少なめ」はカルテには当てない）。借りるは「家賃の情報はまだありません。」のあと「売買の相場を参考に見る」で開く
- 交通：バス停・駅の数と一覧、駅ごとの上り（豊橋方面）・下り（辰野方面）の本数・始発・最終。伊賀良は「地区内に駅はありません。」。車0台なら `NOTICES.carFree` と、冬の場面で使ったバス・電車の便（行き・帰り・帰りの次の便、直通の本数・帰りの本数・乗り場を出る本数）、バスには gofreely へのリンク（`GofreelyLink` をくらしと共通にした）
- 支援制度：出典の行がないので、制度ごとに「飯田市公式サイト（制度のページ）」と確認日を出す。1件もなければ「データ未取得」

| | CPU そのまま | CPU 4倍遅く |
| --- | --- | --- |
| 見出し | 1.6秒 | 2.7秒 |
