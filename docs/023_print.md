# 023 印刷・PDF

- 主な要件：F-07（印刷・PDF）
- 依存：019、020

## 目的

カルテと地区くらべを、ブラウザの印刷機能で A4 縦にきれいに出せるようにする。

## 仕様メモ

- 対象：カルテ・地区くらべ。くらしの場面は MVP では対象外
- 印刷物にも出典と印刷日を入れる
- ヘッダーのボタン類・ナビは印刷しない。カードは途中で切れないようにする
- Tailwind の `print:` で印刷用のスタイルを当てる
- カルテの詳細の「現地で確かめたいこと」は、印刷すると空のチェックの箱つきで出す（2026-11-01 まさゆきさん決定）。紙を持って現地を歩き、ペンでチェックする使い方。画面のチェックはどこにも保存しない（F-02）ので、画面で押したチェックは印刷に反映しなくてよい
