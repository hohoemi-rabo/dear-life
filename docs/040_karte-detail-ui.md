## 決めたこと

- 「この数字から分かること」は、子育て・学校（2026-11-12）と交通（2026-11-13）で出さないことにした。ほかの5つは、その詳細を見直すときに決める（住まいの見本 `docs/design/karte-detail-housing.png` にはこの箱が描かれている）
- 1つの詳細の見直しで決めることは、その詳細のうちに決めてもらう（持ち越さない）
- 台数・家族・地区で見え方が違うところを変えるときは、変える前に「今はこう違う／変えるとこうなる」を見せる

### 決めたこと（2026-11-13 まさゆきさん）

- 見本どおりにする。上から：見出し（番号・問い・地区の札）→ ハザードマップの帯 → 「災害の種類から避難先を探す」の箱 → 「現地で確かめたいこと」→ 黄色い注意書きの帯 → 閉じた「出典・更新日を見る」→ 今の下の2つのボタン（「カルテ一覧へ」「地図で周辺を確かめる」は残す）
- 「この数字から分かること」は出さない（`DetailTexts.knows` を null。印刷も）
- 避難場所の絵と大きい数字（「61か所」）は出さない（見本にない）
- タブは 洪水 → 土砂災害 → 地震。「すべて」はなくし、最初は洪水。鼎だけ4つ目に「大規模な火事」（1か所）を出す（今と同じ。使える場所のない地区には出さない）
- 1行ずつの「地図で見る ↗」は Google マップを別のタブで開く（施設の名前と住所で探す）
- 見出しの下の地区の札（📍中心市街地）は、防災だけでなく7つの詳細すべての PC に付ける
- ハザードマップの帯のボタン「飯田市のハザードマップを開く ↗」の飛び先は、市のページ「防災ハザードマップで危険箇所を確認しましょう」 https://www.city.iida.lg.jp/soshiki/35/hazardmap.html （2026-03-19 更新。いいだWebまっぷのハザードマップと地区別の PDF の案内がある）。リンクを張るだけで、データは取り込まない
- 「現地で確かめたいこと」は見本の2つ：「候補の家から避難場所まで歩いてみる」「家族の集合場所を話し合う」
- 下の注意書きは見本の文「災害時は、飯田市の最新の避難情報を確認してください。」

### 作り方（案）

1. 帯：左に地図の絵、縦線、見出し「候補の家の周りを確認する」と2行の説明（見本の文）、右に緑のボタン。スマホは縦に積む
2. 箱：見出し「災害の種類から避難先を探す」と説明1行。タブ（印＋名前。選んだタブの下に三角）→ 検索欄「施設名・町名で絞り込む」（名前と住所に含まれる文字で絞る。入れた文字はタブを変えても残す）→ 「〇〇に対応する指定緊急避難場所」と件数（「27か所」。絞り込み中は絞ったあとの件数）→ 3件だけの一覧 →「〇〇の避難場所をすべて見る ⌄」で残りを開く（開いたら「閉じる」）。絞り込んで0件なら「見つかりませんでした」
3. Google マップの URL は `https://www.google.com/maps/search/?api=1&query=<名前 住所>`（地区の名前は送らない。施設の公開情報だけ）
4. 地区の札は詳細の見出しの共通部分（`KarteDetailView`）に足す。スマホは今の条件の帯に地区が出ているので足さない
5. 印刷：タブごとに分けず、今と同じく全部の避難場所を1つの一覧で出し、1行ずつ「使える災害」を付ける。帯のボタンは URL を文字で出す
6. 絵：タブの印（洪水・土砂災害・地震・大規模な火事）と帯の地図の絵。届くまでは地図は `childcare-zone-map`、タブの印は今のドット絵 `icon-disaster` を出す

### 作ったもの（2026-11-13）

- 帯と「災害の種類から避難先を探す」の箱は `src/components/karte/EvacuationFinder.tsx`（`HazardMapBand`・`EvacuationFinder`・印刷用の `EvacuationPrintList`）。絞り込み・タブの並び・Google マップの URL は `src/lib/karte/evacuation.ts`（全角・半角と空白の違いは気にせず、名前と住所に含まれる文字で絞る）。市のハザードマップのページは `IIDA_HAZARD_MAP`（`src/lib/map/links.ts`）
- タブは見本に合わせて大きくした（`DetailTabs` の `large`。PC は高さ56px・印36px・文字18px）。鼎はタブが4つになるので、スマホでは印を名前の上に置く（印を消さない）。件数はタブではなく一覧の見出しの右に出す
- 「すべて見る」で開くのは今のタブだけ。タブを変えると3件に戻す。絞り込みの文字はタブを変えても残す
- 下の注意書きは `DetailTexts.notice`（画面と印刷）。「出典・更新日を見る」は閉じた欄
- 地区の札は `KarteDetailView` の `ChosenChips`（PC だけ。住まい・交通・子育て・学校は「選択中」の札の左に並ぶ）
- 検索の虫眼鏡は学区の町名の欄と共通の `SearchMark`（`DetailCard.tsx`）にした
- 一覧には見本どおり施設の名前だけを出し、住所は出さない（2026-11-13 まさゆきさんが今の形で OK）

### 地図へのボタン（2026-11-13 まさゆきさん）

- 交通・防災も子育て・学校と同じく、下の「地図で周辺を確かめる」をなくして「カルテ一覧へ」だけにし、カードの中の「地図で場所を見る」から、その種類だけにチェックを入れて `/chizu` を開く（`?layer=`。種類の対応は `src/lib/map/links.ts` の `FACILITY_LAYER_KINDS`）
- 防災：避難場所だけ（`evacuation_sites`）。ボタンは「災害の種類から避難先を探す」の箱のいちばん下
- 交通：バス停のタブはバス停だけ（`bus_stops`）、電車のタブは駅だけ（`train_stations`）、行ける場所・冬のおでかけのタブはバス停と駅の両方（`transit`）。地区に点がないタブ（伊賀良の電車）には出さない
- 小学校区の塗り分けは、子育て・学校から来たときと同じく最初から出る

### 決めたこと（2026-11-13 まさゆきさん）

- 見本どおりにする。上から：見出し（番号・問い・地区の札・公園の絵 `karte-public`）→「使い道から施設を探す」の箱（6つの大きいタブ → 薄い緑の帯の見出し「〇〇の公園 3か所」→ 1行ずつの名前と「地図で見る ↗」→「掲載施設をすべて見る（〇か所）⌄」→「i」の注意書き「開館日・利用時間は、各施設の案内で確認してください。」）→「下見で確かめたいこと」→ 閉じた「出典・更新日を見る」→「カルテ一覧へ」だけ（地図のボタンはなし。地図には公共施設の点がない）
- タブ（使い道・種類）：子どもと遊ぶ（公園）／本を借りる（図書館）／体を動かす（運動施設）／地域の活動・文化（公民館・文化施設）／手続きをする（市役所・支所）／受診する（病院・診療所）。「学習・交流施設」と「福祉施設」は「地域の活動・文化」に入れる
- 施設が0の地区ではタブを出さない（鼎・伊賀良は「受診する」がなく5つ）
- タブの一覧はその種類を全部出す（中心市街地の公園は23行）。「掲載施設をすべて見る（〇か所）」は地区の公共施設の全部（上郷18・鼎15・伊賀良9・中心市街地56）を種類ごとに開く
- 「地図で見る ↗」は防災と同じく、施設の名前と住所で Google マップを別のタブで開く
- 「この数字から分かること」・絵と大きい数字・種類ごとの数の札は出さない（見本にない）
- 「下見で確かめたいこと」は見本の2つ：「候補の家から、よく使いそうな施設まで歩いてみる」「親子で使いやすい道や入口を確認する」
- 絵：タブの印は、すべり台・本・サッカーボール・公民館の4枚をまさゆきさんが新しく用意する。病院・市役所は交通の行ける場所の印（`errand-hospital`・`errand-office`）を使う。一覧の見出しの左はタブと同じ印
- 「受診する」のタブの一覧の上に「市の施設だけです。民間の診療所は入っていません。」と書く（市の公共施設一覧にあるのは市立の施設だけで、上郷に診療所が1か所しかないように見えないように。印刷も）

### 作り方（案）

1. 箱の見出し「使い道から施設を探す」。タブは PC は3列×2段、スマホは2列（印・使い道を太字・種類を小さく）。選んだタブは緑に塗る
2. 帯の見出し：印・「〈地区〉の〈種類〉」・件数。種類の名前は 公園／図書館／運動施設／公民館・文化施設／市役所・支所／病院・診療所
3. Google マップの URL は防災の `googleMapsSearchHref` を `src/lib/map/links.ts` に移して共用する
4. 「掲載施設をすべて見る」で開いた中は種類ごとの小見出しと名前（「地図で見る」付き）。開いたら「閉じる」
5. 印刷：タブに分けず、地区の公共施設を種類ごとに全部出す。注意書き・確かめたいこと（空の箱）・出典
