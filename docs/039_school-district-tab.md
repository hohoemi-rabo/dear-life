# 039 学区のタブをユーザーの役に立つ形にする

- 主な要件：3章（カルテ）、7章・7.2（学区は「主な学区」として学校名を並べ、範囲は地図で見せる。「入学前に市で確認を」）
- 依存：008（学区）、019・028（カルテの詳細）、021・032（地図）

## 目的

カルテの子育て・学校の「学区」のタブを、移住を考える親が「で、何が分かったの？」とならない形にする（2026-11-12 まさゆきさん：「とにかく、ユーザーの役に立ちそうな方向にしてほしい」）。

## 今の困りごと（2026-11-12 の話）

- 地区を選ぶと、地区と同じ名前の学校（鼎なら 鼎小・鼎中）が大きく出るだけで、新しく分かることがほとんどない
- 親が知りたいこと（この辺りに住んだらどの学校？地区のどこでも同じ？学校まで遠い？）に答えていない
- 地区の端が別の学校の学区になることが画面に出ていない（「主な」と「市で確認して」だけ）
- 下の「この数字から分かること」は、数字のないタブなのに「数字から」で、文は全地区・全タブ共通のひな形（`src/lib/karte/details.ts` の `childcare.knows`・`tip`）

### 1. 取り込み

- 手元のスクリプト `npm run school-zones:sql`（`scripts/build-school-zones-sql.mjs`）
  1. 例規集の規則のページ（HTML）を取り、別表を読む（中学校の欄は縦につながっているので、上の行の学校を引き継ぐ）
  2. 町名ごとの1行にした `data/school_zones.csv` を書く（町名・地区・小学校・中学校・一部かどうか。選べる町は学校を「|」でつなぐ）。CSV は差分を目で確かめるために残す
  3. CSV からマイグレーションを作る
- 市全体を入れ、画面は4地区だけを出す（008・009 と同じ）。地区は `iida_district_map.csv` で付ける。対応表にない町があったら止める
- テーブル `school_zones`（新規）：`town_name`・`district_id`・`elementary_schools text[]`・`junior_high_schools text[]`・`is_partial`・`source_id`。RLS・GRANT・ポリシーを一緒に書く（anon は select だけ）
- 出典 `data_sources` に1行：「飯田市立小学校及び中学校の通学区域に関する規則」別表（飯田市教育委員会）、規則のページの URL、利用条件は「著作権の対象外（著作権法13条1号）」、対象時点は「令和6年11月1日施行」
- 見直し：規則のページの「（令和〇年〇月〇日施行）」が変わったら取り直す。年1回（4月より前）に手元で確かめる手順をこのチケットに書く。定期取得の Worker には入れない（規則はめったに変わらず、表の形が変わると読めなくなるため）
- 国の学区の範囲（`school_districts`）はそのまま残し、地図の塗り分けにだけ使う

### 2. 画面に渡すデータ

- `screen_data()` の地区ごとに `school_zones`（町名・小学校・中学校・一部かどうか）を足す。`src/lib/data/screen-data.ts` に型と読み込みを足す
- 画面では、同じ学校の組み合わせの町をまとめて1行にする（例：「江戸町1〜4丁目」のように丁目をまとめる）。まとめ方は `src/lib/karte/school-zones.ts`（新規）でテストする

### 3. 学区のタブ（カルテの子育て・学校）

- 見出し：「この地区の子が通う学校（学区）」
- 大きい数字：学区の学校の数（上郷・鼎・伊賀良「2校　小学校1・中学校1」、中心市街地「5校　小学校3・中学校2」＝浜井場小・追手町小・丸山小・飯田東中・飯田西中）。中心市街地の八幡町（松尾小・緑ケ丘中）と育良町（伊賀良小・旭ケ丘中）の学校は数に入れない（2026-11-12 まさゆきさん）
- 学区の意味の一言：「学区：住む場所によって、通う公立の小学校・中学校が決まる範囲です。」
- その下：
  - 上郷・鼎・伊賀良：「地区の中は、どの町も同じ学校です。」と、小学校・中学校の名前
  - 中心市街地：「町によって通う学校が分かれます。」と、学校の組み合わせごとの表（小学校｜中学校｜町）。選べる町は「どちらかを選べます」、一部の町は「場所によって分かれます。番地を市で確かめてください」と添える。表の下に「地区の端の町」として八幡町・育良町の2行を出す（町から学校が分かるように残す。5校には数えない）。スマホは表ではなく、組み合わせごとのカードを縦に並べる
- 「学区の範囲を地図で見る」ボタン：地図を学区の塗り分けを付けた状態で開く（地図の URL に学区の表示を足す。地図の範囲は国のデータの目安なので、地図の学区の説明に「通う学校は市の規則で決まります」を添える）
- 出典：① 規則の別表。注意書き（`NOTICES.schoolDistrict`）は今のまま
- 学校のタブの「4校」（地区にある学校。高校なども入る）とは見出しで区別する
- 印刷（`KartePrint`）にも同じ中身を出す

### 4. 「この数字から分かること」をタブごとにする

子育て・学校の4つのタブで文を分ける（今は全タブ共通。`src/lib/karte/details.ts`）。案：

| タブ | 分かること | ひとこと |
| --- | --- | --- |
| 学区 | {地区}に住んだとき、子どもが通う公立の小学校・中学校です。 | 通う学校は住所で決まります。家の候補が見つかったら、町名で学区を確かめましょう。 |
| 学校 | {地区}にある小学校・中学校・高校などです。 | 学区とは別に、地区の中にある学校の数です。 |
| 保育園など | {地区}にある保育園・幼稚園・こども園などです。 | 入れるかどうかは空き状況で変わります。市の窓口で確かめましょう。 |
| 放課後クラブ | {地区}にある放課後児童クラブです。 | 使える学年や時間は、クラブごとに確かめましょう。 |

### 5. ほかの画面の「主な学区」

- 地区くらべの「主な学区」（`src/components/kurabe/rows.tsx`）、くらしの春の場面の文（「小学校は主に{学校名}の学区になります」）と学校のピン（`pin-sheets.ts`）は、今は国の範囲から決めた学校名を出している。市の別表から出すように合わせる（2026-11-12 まさゆきさん）。学校の名前は変わらない（国のデータから出した名前と、別表の5校・各地区の2校が同じ。2026-11-12 確認）。変わるのは出典（国土数値情報 → 市の規則の別表）と、中心市街地の言い方（「主に〜の学区」→「町によって〜に分かれます」。場面のひな形は `drafts.ts` を直して `npm run scenes:sql`）

### 7. 子育て・学校の詳細の作り直し（2026-11-12。まさゆきさん了承済み）

見本は `docs/design/karte-detail-childcare-split.png`（中心市街地）と `karte-detail-childcare-uniform.png`（上郷・鼎・伊賀良）。並び方を見本に合わせ、文言は今のものを生かす（足りないところだけ書く）。

**4タブ共通の枠**

- タブはカードの上（交通と同じ）。名前は「通う学校（学区）」「地区の学校」「保育園など」「放課後クラブ」（「学校」を「地区の学校」にするのは、学区の学校の数と地区にある学校の数を取り違えないため）
- 「この数字から分かること」は出さない（済み）。「現地で確かめたいこと」は幅いっぱい、項目と下見プランのボタンは今のまま
- 「数字の根拠を見る」は「〇〇の出典を見る」の閉じた欄（〇〇は今のタブの名前）
- いちばん下のボタンは「カルテ一覧へ」だけ（子育て・学校の詳細のとき）。地図へは、学区のタブは「学区の範囲を地図で見る」、地区の学校・保育園など・放課後クラブのタブはカードの中の「地図で場所を見る」から行く（2026-11-12 まさゆきさん）
- 地区の学校・保育園など・放課後クラブのタブの中身（絵・大きい数字・一覧）は今のまま

**通う学校（学区）のタブ**

- 学校の絵と「2校／5校」の大きい数字はなくす。カードの頭は地図の絵・見出し・一行の説明
- どの町も同じ地区（`uniform`）：見出し「{地区}で通う学校」、説明「{地区}では、どの町に住んでも同じ学校に通います。」→ 小学校・中学校の2枚の札（学校名を大きく。薄い緑の枠で囲む）→「学区の範囲を地図で見る」と閉じた欄「対象の町名を見る」を横に並べる → 注意書き（`NOTICES.schoolDistrict`）
- 町によって分かれる地区：見出し「町名から学区を調べる」、説明「住まいの候補がある町を選ぶと、通う公立の小学校・中学校が分かります。」→ 町名を選ぶ欄と、右に「学区の範囲を地図で見る」→「{町}の学区」の2枚の札 → 注意書き → 閉じた欄「すべての町名と学区を見る」（中身は今の表。地区の端の町も）
  - 町名を選ぶ欄は**スマホの標準の選択（`<select>`）**。町は丁目ごとに別の行（まとめない）。並びは別表の順（2026-11-12 まさゆきさん：A）
  - はじめは何も選ばない。結果の欄に「町名を選ぶと、ここに学校が出ます」と出す（適当な町を初めから出すと、自分の町と取り違えるおそれがあるため。同日まさゆきさん）
  - 選べる町は札に「浜井場小学校 または 丸山小学校」と「どちらかを選べます」、町の一部で分かれる町は「場所によって分かれます。番地を市で確かめてください」、八幡町・育良町は「となりの地区にある学校です」を添える

**スマホ**：タブは4つ横並びのままカードの上。2枚の札、地図へのボタンと閉じた欄は縦に並べる。町名の欄は幅いっぱい

**印刷**：町名を選ぶ欄は紙では使えないので、「すべての町名と学区」の表を開いて出す

**確かめ**：テストを新しい形に書きかえる。Playwright で 4地区 × スマホ・PC を撮る。本番に出し、まさゆきさんに実機で確かめてもらう

### 8. 地区の学校・保育園など・放課後クラブを学区と同じ形にする（2026-11-13。まさゆきさん了承済み）

学区のタブだけ見本の形にしたので、ほかの3つのタブ（水色の箱の絵・大きい数字・開け閉めの一覧）と並べると違和感がある（2026-11-13 まさゆきさん）。件数は 2〜13（いちばん多いのは中心市街地の保育園などの13）

- 頭：タブの印・見出し「{地区}にある学校」など・一行の説明。件数と内訳は説明の文に入れる（例「小学校1・中学校1・高等学校2の、4校があります。」）。水色の箱の絵と大きい数字はやめる
- 中身：学区と同じ薄い緑の枠に、1か所ずつ白い札（種類の小さな札・名前・住所）。名前は学区の札より一回り小さく。PC は2列、スマホは1列。開け閉めはなくして全部出す
- 下：「地図で場所を見る」は枠の下。地区の学校だけ、今と同じ注意書き
- 印刷：画面と同じ札の形

## 作ったもの

### 取り込み（2026-11-12）

- 読み方は `src/lib/school-zones/rules.ts`（テストは同じ場所の `rules.test.ts`）、手元のスクリプトは `scripts/build-school-zones-sql.mjs`（`npm run school-zones:sql`）
- 学校名は国のデータ・市の教育機関一覧と同じく「飯田市立」を外す（例：上郷小学校）。旭ケ丘は別表の字（「ケ」）のまま。市の教育機関一覧は「旭ヶ丘中学校」なので、名前で突き合わせるときは気をつける
- 同じ町が別表の何行かに「〇〇の一部」で出るとき（上飯田・白山町1丁目、4地区の外の上久堅・千栄・龍江）は1行にまとめ、学校を合わせて `is_partial` を立てる。そのため中心市街地は 119 町（プランの 120 は上飯田を2回数えていた）
- 「の一部」なしで同じ町が2回出る・欄の数が合わない・学校名が「小学校／中学校」で終わらない・対応表にない町がある、のどれかで止まる
- テーブル `school_zones`（主キーは出典と町名。4地区の外の町は `district_id` が null）、出典 `iida_school_zone_rule`（公開、利用条件「著作権の対象外（著作権法第13条第1号）」、対象時点は規則の施行日）
- 対応表に 南常盤町（中心市街地）を足した（97町名）。本番には足した1行だけを当てた（ほかの行は前の版と同じなので、結果はリポジトリの `20261112122610_town_district_map.sql` と同じ）
- 市全体 193 町。4地区は 上郷3・鼎10・伊賀良6・中心市街地119 町（`data/school_zones.csv`）

### 学区のタブ（2026-11-12）

- 中身は `src/components/karte/SchoolZones.tsx`、町のまとめ方は `src/lib/karte/school-zones.ts`（テストあり）
- **地区の端の町は町名で決めない**。「その町の学校が1つも地区の中にない（市の教育機関一覧で地区に入っていない）」町を端の町にする。今は中心市街地の八幡町・育良町だけが当たる。名前の「ヶ」と「ケ」（旭ヶ丘／旭ケ丘）はそろえて比べる。学校の一覧がデータ未取得なら、端の町を分けずにすべての学校を数える
- 組み合わせの並びは別表の順。丁目は3つ以上続けば「江戸町1〜4丁目」、2つかとびとびなら「桜町1・2丁目」
- 「学区の範囲を地図で見る」は `/chizu?…&layer=school_districts`（`schoolDistrictMapHref`）。地図は小学校区の塗り分けと学校だけを出して開く。地図の小学校区の説明に `NOTICES.schoolDistrictMap`（範囲は目安、通う学校は市の規則で決まる）を足した
- 「この数字から分かること」は、はじめ4タブで分けたが、2026-11-12 にまさゆきさんの判断で子育て・学校では出さないことにした（`DetailTexts.knows` を null にすると箱を出さず、「現地で確かめたいこと」を幅いっぱいにする。印刷も出さない）

### 地区くらべ・くらし（2026-11-12）

- 地区くらべの行の名前は「通う小学校（学区）」「通う中学校（学区）」。町によって分かれる地区には「町によって分かれます」を添える。地区の端の町の学校は入れない（カルテと同じ `districtSchoolZones`）
- くらしの春・子どもありの文は「{地区名}に住むと、{通う学校}。」にした（`{通う学校}` は `schoolZonePhrase`。上郷「小学校は上郷小学校、中学校は高陵中学校に通います」、中心市街地「町によって、小学校は…、中学校は…に分かれます」）。前の `{小学校区}`・`{中学校区}` は、圏外用に端末に残った古いひな形のために残し、市の規則の学校名を返す
- **公開の順番**：いまの本番の画面は `{通う学校}` を知らないので、場面のひな形のマイグレーション（`*_scene_templates_data.sql`）は、画面を main に push して公開したあとに当てる
- 学校のピン（子どもなし）も同じ1文。はじめの一言は「通う学校（学区）や学校の場所を、カルテと地図で確かめられます。」
- データについてページの使い道：`iida_school_zone_rule` は「通う小学校・中学校（町ごとの学区）」、`reinfolib_xkt004` は「地図の小学校区の範囲」。ついでに、使い道の抜けていた `mhlw_medical_clinics`（地区の診療所の数）を足した
- 国の中学校区（`reinfolib_xkt005`）は、どの画面にも出さなくなったが、公開のままにする（データについてには出る。2026-11-12 まさゆきさん）

### 子育て・学校の詳細の作り直し（7。2026-11-12）

- タブは交通と同じくカードの上（`OtherDetailCard` の `tabsAbove`）。名前は「通う学校（学区）」「地区の学校」「保育園など」「放課後クラブ」。括弧の付いた名前は、スマホでは括弧の前で2行にする（`DetailCard` の `TabLabel`。4つ横並びに収めるため）
- 通う学校のタブは `SchoolZones.tsx` の `SchoolZonePanel`（`PanelContent.head` に入れ、絵と大きい数字は出さない）。印の絵は、まさゆきさんの生成AIの絵（2026-11-12 受け取り）。タブ4つ（`childcare-tab-*`。スマホでは出さない）・カードの頭の地図（`childcare-zone-map`）・地図へのボタン（`childcare-map-button`）・PC の「選択中」の札（`childcare-chip-family`）。1枚ずつの印は `DetailCard` の `PropIcon`
- 町名を選ぶ欄は `<select>`。町は `SchoolZoneSummary.towns`（丁目ごと・別表の順・端の町の印 `edge`）。2校から選べる町は学校名の途中で折り返さない
- 紙では、町名を選ぶ欄を出さず、「対象の町名」「すべての町名と学区」の欄を開いて出す
- 地区の学校・保育園など・放課後クラブは、一覧の下に「地図で場所を見る」（`FacilityMapLink`）。地図は `?layer=schools`・`childcare`・`after_school_clubs` でその種類だけを出して開く（`facilityMapHref`。地図の `initialKinds`）
- ページの下のボタンは、子育て・学校だけ「カルテ一覧へ」1つ。出典の欄は「〇〇の出典を見る」で、PC でも閉じて始める（`Basis` の `title`）

### 地区の学校・保育園など・放課後クラブ（8。2026-11-13）

- 中身は `src/components/karte/ChildcareFacilities.tsx` の `ChildcareFacilityPanel`。頭は学区と共通の `PanelTitle`（`DetailCard`）
- 説明の文は `facilityCountSentence`、種類の並びは `childcareGroups`（`src/lib/karte/facilities.ts`）。届いた順だと「中学校 → 小学校」「その他 → こども園」になるので、小学校 → 中学校 → 高等学校、保育所 → こども園 → 認可外 → その他 にそろえた
- 種類が1つだけ（放課後クラブ）は、どの札も同じなので種類の小さな札を出さない
- 使わなくなった `SubkindBreakdown`・`FacilityListingWithMap` は消した

### 見直しの手順（年1回、4月より前）

1. `npm run school-zones:sql` を動かす。規則のページの「(令和〇年〇月〇日施行)」と別表を読み直し、`data/school_zones.csv` を書き直す
2. 「変更なし」なら終わり（出典の確認日だけが変わる版は書き出さない）。マイグレーションが出たら、`git diff data/school_zones.csv` で変わった町を目で確かめる
3. 対応表にない町名で止まったら、`data/iida_district_map.csv` に足して `npm run town-map:sql` で当ててから、もう一度動かす
4. `npm test` を通してから `apply_migration` で当て、ファイル名を `list_migrations` の番号に合わせる
5. 学校の名前や、中心市街地の5校・ほかの地区の2校が変わったら、学区のタブ・地区くらべ・くらしの文を見直す
