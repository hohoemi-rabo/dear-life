# 021 05 地図 画面（MapLibre）

- 主な要件：F-06（地図）、7章（背景地図）、7.2（学区の扱い）、8章（地図の位置は目安）、8.2（圏外では背景が出ない）
- 依存：008、009、015

## 目的

学校・保育・バス停・避難場所の位置関係と小学校区の範囲を地図で確かめられる画面を作る。

## 仕様メモ

- MapLibre GL JS（無料）で表示。下地は国土地理院の地理院タイル（標準地図・航空写真）、立体は標高タイル。代替は OpenStreetMap
- 最初は真上から見た平面。「立体で見る」で地図を斜めに倒し、山の起伏をつける。立体では下地を航空写真にもできる。動きが重い機種のために平面に戻せる
- 種類ごとに表示・非表示（学校・保育・バス停・避難場所）。点をタップすると名称・住所・出典
- 小学校区は面で表示。距離は表示しない
  - `school_districts` には4地区にある学校の学区だけが入っている（008）。`geometry` は API がタイルの境目で切った切れ端を並べた MultiPolygon なので、輪郭の線をそのまま引くとタイルの境目にも線が出る。面の塗りだけにするか、画面側でつなぎ直す（例：turf の union）
- 「地図の位置は目安です」と書く。地理院タイルの出典表記を地図上に出す
- 「いいだWebまっぷ」へのリンク（データは取り込まない）を検討する
- MapLibre はサイズが大きいので、この画面だけで遅延読み込みする（`next/dynamic` + `ssr: false`）
- 地理院タイルの利用条件（出典表記・商用利用）を確認する
