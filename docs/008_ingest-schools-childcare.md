# 008 学区・学校・保育施設の取得（XKT004〜007）

- 主な要件：7章（小学校区・中学校区・学校・保育園・幼稚園等）、7.2（データの扱い）、10章（年1回の取り直し）
- 依存：004、005

## 目的

不動産情報ライブラリ API の XKT004（小学校区）・XKT005（中学校区）・XKT006（学校）・XKT007（保育園・幼稚園等）を取得して保存する。

## 仕様メモ

- 範囲データはタイル単位の取得。飯田市の4地区をおおう範囲のタイルを洗い出し、呼び出し回数が多ければ数日に分ける（1回 50 回まで）
- 学校は市「教育機関一覧」、保育施設は市「子育て施設」（2024-11-05更新）で補う（補完は 009 と協力）
- 点データは住所の町名で4地区に振り分ける（004）
- 学区は「この地区の主な学区」として学校名を並べ、範囲は地図で見せる。「入学前に市で確認を」と添える
- 小学校区と地区は範囲が違うので、同じ範囲の情報として混ぜて表示しない
- 年1回（4月以降）取り直し、結果をまさゆきさんが目で確認する
