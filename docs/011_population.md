# 011 地区別人口（e-Stat）の入手と取り込み

- 主な要件：7章（地区の人口）、11.1（入手方法・優先度 高）、6.1（秋の場面）、F-05（地区くらべ）
- 依存：004

## 目的

市のデータに地区別人口がないため、国勢調査の小地域集計（e-Stat）を町名ごとに取り、対応表で4地区に合算できるか確かめて取り込む。

## 仕様メモ

- 年齢構成（例：0〜14歳・15〜64歳・65歳以上）も出す
- 対象時点（国勢調査の年）を必ず表示する
- 取れなかった場合は画面で「データ未取得」と出す（F-09）。入手できるまで他の画面の実装を止めない
- 更新は年1回・手動

## 調べた結果（2026-10-26）

- 使う表：e-Stat「令和2年国勢調査 小地域集計（町丁・字等別）」の「年齢（5歳階級、4区分）別、男女別人口」（統計表 ID T001082）。統計GISの「統計データダウンロード」→ 国勢調査 → 2020年 → 小地域（町丁・字等別）から、長野県の ZIP（Shift_JIS の CSV）を API キーなしで取れる。飯田市全体は 98,164人で、令和2年国勢調査の飯田市の人口と一致する
- 利用条件：政府標準利用規約（第2.0版）（CC BY 4.0 互換）。商用可・出典の表示が必要。飯田市のオープンデータではないので市の了承は不要
- 令和7年国勢調査は人口等基本集計が 2026-09-29 に公表済み。小地域集計は「基本集計の公表後に集計し、秘匿処理をして速やかに公表」とされていて、2026-10-26 の時点ではまだ見つからなかった。出たら差しかえる（下の「更新の手順」）
- 合算のしかた：
  - HYOSYO（表章単位）が 2・3 の行（町丁・字等）だけを足す。4（丁目など、その下の区分）は 3 の内訳なので足さない
  - 国勢調査は「上郷」「伊賀良」「南信濃」「竜丘」「三穂」を地区名のまま1つの町丁・字等にしている（中の区分も「上郷下黒田北」「伊賀良北方」のように対応表の町名と分け方が違う）。対応表の町名に当たらず、地区名と同じ名前のものはその地区に入れる
  - 国勢調査の伊賀良には「伊賀良三尋石」（340人）が入っている。三尋石の市営住宅の住所は大瀬木（長野県の県営住宅等一覧）で、三尋石は大瀬木の中の地名とみて伊賀良に含める（対応表は変えない。まさゆきさんの確認で見てもらう）
  - 対応表にない「横手」（数字が伏せられ、羽場の大休に合算）、「大平」「松川入」（0人）は飛ばす。人数には影響しない
  - 伏せられた人数（X）が別の地区の町丁・字等に合算されていたら止める。4地区の中に伏せられた町丁・字等はなかった
  - 羽場（羽場町・大休など）は中心市街地に入れない（要件 2.1）。「中央通り」「松尾町」は国勢調査で2か所に分かれていて、両方とも中心市街地に入る
- 結果（2020-10-01 現在。年齢不詳があるので3区分の合計は総数以下）：

| 地区 | 総数 | 0〜14歳 | 15〜64歳 | 65歳以上 |
|---|---|---|---|---|
| 上郷 | 13,534 | 1,769 | 7,445 | 4,116 |
| 鼎 | 13,135 | 1,727 | 7,126 | 4,052 |
| 伊賀良 | 13,285 | 1,860 | 7,420 | 3,888 |
| 中心市街地 | 14,633 | 1,610 | 7,620 | 5,153 |

## 作ったもの

- `src/lib/population/census.ts`：小地域集計の CSV を読み、4地区に合計して SQL を作る（テストは `census.test.ts`）
- `scripts/build-population-sql.mjs`（`npm run population:sql`）：e-Stat から ZIP を取り、`supabase/migrations/<版番号>_population_data.sql` を書き出す。中身が前と同じなら何もしない
- `supabase/migrations/20261026103415_population_source.sql`：出典（`data_sources` の `estat_census_small_area`）
- `supabase/migrations/20261026103416_population_data.sql`：4地区の人口（Supabase に適用済み）

## 更新の手順（年1回・手動）

1. e-Stat の統計GIS「統計データダウンロード」→ 国勢調査で、新しい国勢調査の小地域集計（町丁・字等別）が出ているか確かめる。出ていなければ何もしない（国勢調査は5年ごと）
2. 出ていたら、`src/lib/population/census.ts` の `CENSUS_NAME`・`CENSUS_DOWNLOAD_URL`（「年齢（5歳階級、4区分）別、男女別人口」の表の statsId）・`CENSUS_AS_OF`（調査日）を差しかえる
3. `npm run population:sql` を動かす。対応表にない町丁・字等で止まったら `data/iida_district_map.csv` に足して `npm run town-map:sql` で当ててから、もう一度動かす。項目名が変わって止まったら `COLUMN_LABELS` を直す
4. `npm test` を通し、Supabase MCP の `apply_migration` で当てて、ファイル名の版番号を `list_migrations` に合わせる
   - `population` の主キーは（地区, 対象時点）。今の作りは出典の行を消して入れ直すので、残るのは最新の国勢調査だけになる。前回との比較を出したくなったら、そのときに作りを変える
