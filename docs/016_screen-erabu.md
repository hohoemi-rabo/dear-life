# 016 01 えらぶ 画面

- 主な要件：F-01（えらぶ）、F-10（選択への返事）、4章（えらぶ画面での返事）、5章（相場の表示）、11.1（質問の言い回しと順番）
- 依存：013、014、015

## 目的

質問に1つずつ答えて暮らし方を選び、選ぶたびに本物のデータが短く返ってくる画面を作る。サービスの入口で、選ぶこと自体をゲーム感覚にする。

## 仕様メモ

- 1画面に1問。順番の案：家族 → 地区 → 家 → 車 → 大切にしたいこと（デザインイメージと同じ）。言い回しと順番は作りながら提案する
- 入力はすべてタップ。戻って選び直せる。任意の質問は飛ばせる
- 上部に進み具合（家族 → 地区 → 家 → 車 → 大切なこと）と、それまでに選んだ条件のチップ
- 選ぶたびの返事（F-10・4章）：

| 選択 | 返事 |
| --- | --- |
| 住む地区 | 地区の範囲と、土地の真ん中の値・件数 |
| 子ども1人以上 | 地区の保育園・幼稚園等と小学校の数 |
| 家：買う・新しめ | 築20年以内の中古戸建ての真ん中の値と件数＋必ず「件数少なめ・参考程度」 |
| 家：買う・古め | 築21年以上の中古戸建ての真ん中の値と件数 |
| 家：借りる | 「家賃の情報はまだありません」 |
| 車：0台 | 地区のバス停の数 |

- 相場には件数・件数ラベル・出典（国土交通省 不動産情報ライブラリ・対象期間）・「現在の売り出し価格ではなく、過去の取引の参考値です」を必ず付ける
- 「中央値」ではなく「真ん中の値」と書く
- 選択肢の絵（家の種類・地区など）は 013 のドット絵を使う
- 最後に「くらしを見る」へ。条件は URL パラメータで渡す
- 地区は「対象地区：上郷・鼎・伊賀良・中心市街地」と明記する
- 点数化・おすすめはしない

## 作ったもの（2026-10-26）

- ルートは `/erabu`（`src/app/erabu/page.tsx`）。中身は `src/components/erabu/ErabuFlow.tsx`（Client Component、`<Suspense>` の中）。トップ（`/`）からは「暮らし方をえらぶ」ボタンで入る
- 質問の並び・進み方は `src/lib/erabu/questions.ts`、返事の出し分け（要件 4章の「えらぶ画面での返事」の列）は `src/lib/erabu/replies.ts`。どちらも画面から独立した関数でテストする
- 今の質問は URL パラメータ `q`（district・family・housing・car・priorities）に持つ。質問の移動は `router.push`（ブラウザの「戻る」で前の質問に戻れる）、選び直しは `useConditions` の `router.replace`（履歴を増やさない）。「くらしを見る」へ渡す URL には `q` を入れない（`conditionsHref`）
- 地区を選ぶまでは、後ろの質問を開けず「次へ」も押せない。家族・家は初期値（大人2人・子ども1人・買う・新しめ）が入っているので、そのまま次へ進める。車・大切にしたいことは「飛ばす」で未選択・なしにして進む。車はもう一度押すと未選択に戻る
- 上部の進み具合は押して戻れる。選んだ条件のチップは、今の質問より前の答えだけを出す（まだ聞いていない初期値は出さない）
- 返事は `ErabuReplyCard`。データは返事のところだけ `ScreenDataBoundary` で囲んで読む（読み込み中・失敗しても質問には答えられる）。相場には件数・件数ラベル・注意書き・出典・対象期間（`2021年第1四半期〜2026年第1四半期`）を付ける。土地は1㎡あたりの値に「1坪あたり 約◯万円」を添える
- 「新しめ」は件数によらず「件数少なめ・参考程度」を付ける（`CountBadge` の `alwaysFew`）
- 数の返事：保育園・幼稚園等は市「子育て施設」の保育施設すべて（放課後児童クラブは入れない）、小学校は市「教育機関一覧」の区分が「小学校」のもの、バス停は地区のバス停すべて
- 共通で使える部品を足した：`DataSourceNote`（出典の行から出典・対象・確認日／取得日を出す）、`DataStateMessage`（「該当なし」「データ未取得」の表示。022 で見直す）、`PixelImage`（ドット絵1枚を整数倍で出す）、`formatManYen`・`formatQuarterRange`（`src/lib/format.ts`）。テスト用の `src/test/screen-data-fixture.ts`
- 選択肢の絵：地区は目印（013）、家族は人数に合わせた家族の絵（大人2人・子ども3人までは描いた人数、それより多いときは描ける人数で出す）、車は 0台＝バス・1台以上＝車。家の絵は 013 になかったので3枚（`house-new`・`house-old`・`house-rent`）を描き足した

### まさゆきさんへの提案（質問の順番と言い回し）

- 順番は **地区 → 家族 → 家 → 車 → 大切なこと** にした（デザインイメージは家族が先）。返事はどれも「その地区の」データなので、地区が決まっていないと家族の質問で保育園・小学校の数を返せないため
- 言い回し：「どの地区で暮らす？」「何人で暮らす？」「どんな家で暮らす？」「車は何台？」「大切にしたいことは？」。それぞれの下に一言の説明（`questions.ts` の `lead`）
- 家の選択肢の下に「築20年以内の中古戸建て」「築21年以上の中古戸建て」「アパート・借家」、車の選択肢の下に「バスや電車で」「家族で1台」「1人1台など」と添えた
