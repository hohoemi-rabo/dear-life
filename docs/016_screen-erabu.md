# 016 01 えらぶ 画面

- 主な要件：F-01（えらぶ）、F-10（選択への返事）、4章（えらぶ画面での返事）、5章（相場の表示）、11.1（質問の言い回しと順番）
- 依存：013、014、015

## 目的

質問に1つずつ答えて暮らし方を選び、選ぶたびに本物のデータが短く返ってくる画面を作る。サービスの入口で、選ぶこと自体をゲーム感覚にする。

## 仕様メモ

- 1画面に1問。順番の案：家族 → 地区 → 家 → 車 → 大切にしたいこと（デザインイメージと同じ）。言い回しと順番は作りながら提案する
- 入力はすべてタップ。戻って選び直せる。任意の質問は飛ばせる
- 上部に進み具合（家族 → 地区 → 家 → 車 → 大切なこと）と、それまでに選んだ条件のチップ
- 選ぶたびの返事（F-10・4章）：

| 選択 | 返事 |
| --- | --- |
| 住む地区 | 地区の範囲と、土地の真ん中の値・件数 |
| 子ども1人以上 | 地区の保育園・幼稚園等と小学校の数 |
| 家：買う・新しめ | 築20年以内の中古戸建ての真ん中の値と件数＋必ず「件数少なめ・参考程度」 |
| 家：買う・古め | 築21年以上の中古戸建ての真ん中の値と件数 |
| 家：借りる | 「家賃の情報はまだありません」 |
| 車：0台 | 地区のバス停の数 |

- 相場には件数・件数ラベル・出典（国土交通省 不動産情報ライブラリ・対象期間）・「現在の売り出し価格ではなく、過去の取引の参考値です」を必ず付ける
- 「中央値」ではなく「真ん中の値」と書く
- 選択肢の絵（家の種類・地区など）は 013 のドット絵を使う
- 最後に「くらしを見る」へ。条件は URL パラメータで渡す
- 地区は「対象地区：上郷・鼎・伊賀良・中心市街地」と明記する
- 点数化・おすすめはしない
