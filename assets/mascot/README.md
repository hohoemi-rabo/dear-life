# マスコットの動きの元（042）

まさゆきさんが生成AIで作ったマスコットのアニメーション。画面にはそのまま出さず、`npm run mascot` が背景を消してコマを横に1列に並べた WebP（`public/mascot/`）を作る。差しかえるときは同じ名前で置きかえて流し直す。一覧は `src/lib/mascot/assets.ts`。

用意するときの決まり（042 の「決めたこと」）：背景は白に近い単色か透明（体と同じクリーム色はだめ）、エプロンは見本の青緑、エプロンのほかに青緑・青を使わない、最後のコマが最初につながるループ。

| ファイル | 使う場所 | 中身 |
| --- | --- | --- |
| `kamisato-sweep-spring.gif` | くらし・上郷・春（右上の石段の中ほど） | ほうきで掃く。着物風の服に花の印。480×480・58コマ・1コマ80ミリ秒。元は `春.gif`（2026-11-15） |
| `kamisato-sweep-summer.gif` | くらし・上郷・夏 | ほうきで掃く。エプロン。480×480・58コマ・1コマ80ミリ秒（約4.6秒）。背景は5色だけのクリーム色で、頭のてっぺんの明るいところとほとんど同じ色。元は `mascot_sweep_flat_loop.gif`（2026-11-15。はじめは4季節とも使い、同日に夏だけにした） |
| `kamisato-sweep-autumn.gif` | くらし・上郷・秋 | ほうきで掃く。ニットの服に葉の印。背景の内側に、ふちとほんの少しちがう色の四角があるので、ふちの色との差が5以内の色も背景として消す（`nearBackground`）。元は `秋.gif`（2026-11-15） |
