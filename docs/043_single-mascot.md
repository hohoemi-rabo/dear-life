# 043 一人のときだけ「わが家」にぽてりが出る（裏技）

- 主な要件：8章
- 依存：016（えらぶの家族）、018・028（くらしの「わが家」 `HomeCard`）、019・040（カルテの「わが家の設定」 `ConditionsPanel`）、042（ぽてり・服の色）
- 元の絵：まさゆきさんが用意した `春.png`・`夏.png`・`秋.png`・`冬.png`（1254×1254、マゼンタの背景、季節の服を着た立ち姿のぽてり。2026-11-18 にダウンロードに届いた。合っていることはまさゆきさんが確認済み）

## 目的

えらぶの家族で「一人」を選んだ人だけが気づく、ひっそりした裏技。くらしの「わが家」とカルテの「わが家の設定」に、ぽてりが登場する。

## 決めたこと（2026-11-18 まさゆきさん）

- 出す条件は、えらぶで **大人1人・子ども0人** を選んだときだけ（URL の家族の値で決める。ほかの家族では出さない）
- 出す場所：くらしの「わが家」（`HomeCard`）と、カルテの「わが家の設定」（`ConditionsPanel`）
- **スマホでは出さない**（どちらの欄も、いまは PC の幅だけに出ている。スマホは一旦出さない）
- 動きは **まばたきだけ**。目を左右に動かすのはしない（試作では左右も動かしたが、やめる）
- 服は、くらしで見ている季節（URL の `s`）の服。カルテもくらしの季節を引き継ぐ（042 と同じ）
- この2か所のぽてりは **押しても服の色を変えられない**（パレットを出さない）。ただし、ほかの場所（くらし・カルテの見出し・地区くらべなど）で色を変えていたら、その色で出す（042 の `useApronColor` の色を使う）
- 「〇人で見つけた」などの印は出さない。ひっそり出すだけ
- ぽてりは **人の絵の横に並べる**（人の絵の代わりにはしない）。「一人じゃないよ」と伝えたいから（2026-11-18 まさゆきさん）

## 試作（2026-11-18）

- `~/dear-life-screenshots/single-mascot-blink/`（`{spring,summer,autumn,winter}-small.gif` は高さ180px、`-large.gif` は600px。この試作はまばたきと左右の目の動きの両方が入っている）
- 作り方：元の絵の目のまわりを、まわりの肌の色でなめらかに埋め、閉じた目（下向きの弧）を描く。半分閉じたコマもはさむ。目の位置は4枚とも同じ（左目 x452〜481・y358〜387、右目 x645〜680・y413〜447）。左目は頭のふちに近いので、背景のマゼンタを拾わないようにする
- 画面に出す大きさでは目が3px前後なので、まばたきはわかるが、細かい動きは見えにくい
