# 絵の元の画像（028）

まさゆきさんが生成AIで作った絵の元の画像。画面にはそのまま出さず、表示用に縮めた WebP を作って使う。差しかえるときは同じ名前で置きかえる。

- `common/`：4地区で使い回す絵（家族・家・車・カルテ・詳細の絵など）と、飯田市全体の絵

- `chushin/`：中心市街地の絵（地区の絵・えらぶ・くらし・行事）
- `kanae/`：鼎の絵（地区の絵・えらぶ・くらし・行事）
