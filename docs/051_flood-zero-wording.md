# 051 水害被害額の「0円」を「記録なし」と分かるようにする

- 主な要件：5章（データの見せ方）、7.3（出典・注意書き）
- 依存：041

## 目的

地区くらべの「いまの街と」と、カルテの防災の「雨と風は、どれくらい？」に出る飯田市の水害被害額が「0円」になっている。値は国の統計どおりだが、「0円」だけだと「飯田は水害がない街」と受け取られるおそれがあるので、「この10年、国の統計に記録がない」という意味だと分かるようにする（2026-11-23 まさゆきさん）。

## 確かめたこと（2026-11-23）

- e-Stat「水害統計調査」表-25（水害原因別市区町村別一般資産等被害額）の 2014〜2023年の10年分を取り直して見た。飯田市の行は10年ともない。表には被害が記録された市区町村だけが載る（同じ年に長野県の長野市・松本市・諏訪市などや、近くの喬木村・大鹿村（2020年）が載っている）
- 古い年には飯田市の行がある：2006年 36,020千円（内水）、2010年 203,329千円（土石流など）。表の作りのせいで抜けているのではない
- 2024年の表-25 は、まだ e-Stat に出ていない
- 値（`data/compare/stats.csv` の 0円）はそのままでよい。直すのは見せ方だけ

## 決まっていること（2026-11-23 まさゆきさん：案1）

- 飯田市の水害被害額が 0 のときは、値を「0円（記録なし）」と出す
- 注意書きに「2014〜2023年の国の統計に、飯田市の住まいや店の水害被害の記録はありません。」を足す（年は対象期間から入れる）
- 2006年・2010年の記録には触れない（案2 にはしない）
- 地区くらべ「いまの街と」の表・印刷と、カルテの防災の「雨と風は、どれくらい？」の両方をそろえる
