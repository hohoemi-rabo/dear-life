# 002 アプリの土台（デザインの基本・共通レイアウト・テスト）

- 主な要件：8章（対応端末・操作性・読みやすさ・表示の注意書き）、7.3（禁止事項）、F-08
- 依存：001

## 目的

全画面で使う見た目の決まりごとと共通部品を先に作り、画面ごとのチケットで迷わないようにする。テストランナーもここで入れる。

## 仕様メモ

- **デザインの基本方針：「絵はドット絵、数字は本物」のギャップを見せる**（要件 1章・8.1）。ドット絵の側（整数倍表示・ドット風の枠・季節の色）と実データの側（ふつうのフォント・大きくはっきりした数字・件数・出典・確認日、基本色のみ）を見た目で分ける。テーマの色や共通部品はこの2系統を前提に作る。場面の中の実データは、会話ウィンドウ風の枠にドット風ではない文字で出す
- デザインイメージ（`docs/design/`）の雰囲気：生成りの背景、深緑のメインボタン、角丸カード、季節ごとのアクセント色（春=桜色、夏=青、秋=橙、冬=水色）。**あくまでイメージ**なので色の値はここで決め直してよい
- 文字はふつうのフォント（ドット風にしない）。`next/font` で日本語フォント（Noto Sans JP など）を読み込む。Geist は外す
- スマホ幅 375px 基準。PC はデザインイメージ PC版のように左（わが家の設定）・中央（場面）・右（行事・確かめる）の3列を想定
- タップ領域 44px 以上
- ヘッダー：ロゴ「DearLife／飯田移住カルテ」、ステップ表示（01 えらぶ／02 くらしを見る／03 カルテ）、「データについて」へのリンク
- フッター：「対象地区：上郷・鼎・伊賀良・中心市街地」「個人が公開データをもとに作成したもの」、対象期間・除外した取引・出典の短い説明と「データについて」へのリンク（F-08）
- サイト名・ロゴに国土交通省・飯田市の名称やマークを使わない
- `<html lang="ja">`、`metadata` でタイトル・説明を設定
