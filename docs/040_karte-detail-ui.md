## 目的

## 決めたこと

- 「この数字から分かること」は、子育て・学校（2026-11-12）と交通（2026-11-13）で出さないことにした。ほかの5つは、その詳細を見直すときに決める（住まいの見本 `docs/design/karte-detail-housing.png` にはこの箱が描かれている）
- 1つの詳細の見直しで決めることは、その詳細のうちに決めてもらう（持ち越さない）
- 台数・家族・地区で見え方が違うところを変えるときは、変える前に「今はこう違う／変えるとこうなる」を見せる
