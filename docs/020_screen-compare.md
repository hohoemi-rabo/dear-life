# 020 04 地区くらべ 画面

- 主な要件：F-05（地区くらべ）、5章（相場の表示）、11.1（4地区のスマホでの並べ方）
- 依存：019

## 目的

4地区を同じ項目で横に並べてくらべられる画面を作る。

## 仕様メモ

- 項目：土地の真ん中の値と幅、中古戸建て（築20年以内／21年以上）、件数ラベル、主な学区、施設の数、人口、季節ごとの主な行事
- 件数が少ない値には件数ラベルを付ける。伊賀良の土地は幅を省略しない
- 点数・順位・色の良し悪しで優劣をつけない（並び順も固定）
- 選んだ地区を目立たせるのはよいが、「おすすめ」には見せない
- スマホ（375px）で4地区をどう並べるか：見やすさを優先して作り、画面を見ながら提案する（例：項目ごとに4地区を縦に並べる／横スクロールの表）
- 出典・対象時点を表の下にまとめて出す
- 印刷は 023

## 決めたこと（2026-10-27）

- 項目：住まいの相場（土地の㎡単価の真ん中の値と幅・中古戸建て 築20年以内／21年以上の総額の真ん中の値、すべて件数と件数ラベル）、主な学区（小学校・中学校）、施設の数（学校・保育園・幼稚園等・放課後児童クラブ・指定緊急避難場所・公共施設・バス停・駅）、人口（総数・年齢3区分の割合）、季節ごとの行事（その季節の行事を全部。1季節あたり今は最大3件）
- 地区の並びは地区マスタの順で固定。選んだ地区（URL の `d`）は薄い緑の背景と「選んだ地区」の文字だけを付ける。地区を選んでいなくても見られる（そのときは目印なし、下に「地区をえらんで、くらしを見る」）
- 件数ラベルはカルテと同じ `countLabel`。マスの「該当なし」「データ未取得」は短く出し、意味は表の下の「出典と対象時点」で1回だけ説明する
- スマホ（lg 未満）：項目ごとに4地区を縦に並べる（地区名が左、値が右）。数字1つだけの行（施設の数・人口）は 2×2 に詰める。375px で横にはみ出さない。全体の長さは約7,000px（相場と行事が長い）
- PC（lg 以上）：項目を行、地区を列にした表。分野ごとに見出しの行を入れ、注意書きは表の下にまとめる
- 出典は表の下にまとめて、出てくる順に1回ずつ。相場は集計の対象期間、人口は国勢調査の時点、行事は資料と確認日
- 移動：カルテ ⇔ 地区くらべ ⇔ くらしのあいだで、条件と季節（`s`）を持ち回る（`seasonalHref`）
