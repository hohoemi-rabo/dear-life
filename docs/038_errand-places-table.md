## 目的

037 で作ったカルテの交通の「用事の場所」のタブを、s1・s2 の見せ方にする。**出す情報は今のまま**（減らさない）で、見せ方だけを変える（まさゆきさん）。

## 決めたこと（2026-11-12 まさゆきさん）

- **表の形**：見出しの行（行き先／平日の行きの便／直通で行けるバス停）。左にまとまりの絵と名前、右に行き先ごとの行。本数は太字（例「4〜14本／日」）、バス停は「25か所中18か所」の形。数字は本物（見本の数は仮）
- **まとまりと順番**：**買い物 → 病院 → 市役所 → 学校 → 駅**（「通院」ではなく「病院」）
- **買い物**：エリアごとに**店を全部出す**（伊賀良2・ほかは3）。2店で切らない
- **たたむ／開く**：はじめは 買い物・病院・市役所。「ほかの行き先を見る」で、s2 のように**同じ表のまま下に** 学校・駅 が続いて出る。ボタンは「ほかの行き先を閉じる」（^）に変わる
- **今の情報の入れ先**（どれも残す）：
  - 店の名前 → 公式ページへのリンク（↗）のまま。そばにバス停がない店（キラヤ 黒田店）は「そばにバス停がないため、バスでは数えていません」
  - 診療所（クリニック）→ 病院のまとまりに1行。便の欄に「{地区}の中に{N}か所」、バス停の欄は空ける。国の一覧の時点・歯科は入っていない、の一文も残す
  - 駅 → 駅のまとまり。便の欄に「電車 {N}本／日」と上り・下りの内訳。伊賀良は「地区内に駅はありません」
  - 高校 → 学校のまとまりに「近くの高校（紹介）」として名前だけ
  - 注意書き・時刻表の日付・店を確かめた日・gofreely の枠も残す
- **スマホ（375px）**：4列は入らないので、行き先ごとに「名前／本数／バス停の数」を縦に積む
- **絵**（`assets/illust/common/`）：
  - `errand-icons.png`（まさゆきさんが用意）：1枚に **買い物・病院・市役所・家とバス停** の4つ（透過、隙間で切り分ける）。家とバス停は gofreely の枠の絵
  - `errand-station.png`（まさゆきさんが用意）：駅
  - 学校は今の `reply-school.png` を使う
