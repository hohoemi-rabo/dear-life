## 決めたこと

- 「この数字から分かること」は、7つの詳細すべてで出さない（2026-11-13 まさゆきさん：「この数字からわかることは消してください」。住まいの見本にはこの箱が描かれているが、出さない）。画面・印刷とも消し、文言（`DetailTexts.knows`・`housingKnows`）と電球のドット絵 `icon-bulb` も消した
- 1つの詳細の見直しで決めることは、その詳細のうちに決めてもらう（持ち越さない）
- 台数・家族・地区で見え方が違うところを変えるときは、変える前に「今はこう違う／変えるとこうなる」を見せる

### 決めたこと（2026-11-13 まさゆきさん）

- 見本どおりにする。上から：見出し（07・問い・札「飯田市全体」・今の見出しの絵 `karte-support`）→「目的から支援制度を探す」の箱（3つのタブ → 見出し「移住の支援」と札「掲載3件」→ 1行ずつ 札・題・正式な名前・「公式ページを見る ↗」→「掲載制度をすべて見る（13件）」）→「申し込む前に確かめたいこと」の箱 → 閉じた「出典・確認日を見る」→「カルテ一覧へ」だけ（地図のボタンはなし）
- 見出しの下の札は、地区名ではなく「飯田市全体」（地区だけの制度と受け取られないように）
- タブは 移住（相談・体験・お金）／住まい（家探し・お金）／子育て（妊娠・出産・子育て）。制度のない種類はタブを出さない（「その他」は今0件。増えたら4つ目のタブ）。タブを選ぶとその種類を全部出す（子育ては7行）。「すべて見る」は3つの種類をまとめて種類ごとに開く
- 制度ごとの絵は出さない（見本の吹き出し・靴・コインは13枚になり、制度が増えるたびに要るため。2026-11-13 まさゆきさん）。行の左は札
- ボタンの文言は全部「公式ページを見る ↗」にそろえる（見本は制度ごとに違う）
- 「この数字から分かること」・絵と大きい数字は出さない
- 今の注意書きと「窓口で確かめたいこと」は、「申し込む前に確かめたいこと」の箱1つにまとめる。文は「対象になる条件・受付の期間・申し込む時期を、公式ページや窓口で確かめてください。」（見本の「申請のタイミング」を分かりやすくした）。左に書類の絵
- 1行の題と札（誰が見ても分かる言葉で。役所の言葉は題に使わない。お金の制度の札は「お金」にそろえる。条件のあるお金は「調べる」「知る」と書き、言い切らない）。並びはこの表の順（子育ては相談が最初）：

| 種類 | 札 | 題 | 正式な名前（小さく） |
|---|---|---|---|
| 移住 | 相談 | 移住のことを、市の窓口に相談する | 移住相談（結いターン移住定住推進課） |
| 移住 | 体験 | 数日間、飯田で働いて暮らしてみる | お試し移住体験「結いターンシップ」 |
| 移住 | お金 | 都市部から移住して働く人への支援金を調べる | 移住支援金（UIJターン就業・創業移住支援事業補助金） |
| 住まい | 家探し | 市が紹介している空き家を探す | 飯田市空き家バンク |
| 住まい | お金 | 空き家の修理や引っ越しにかかるお金の補助を調べる | 空き家バンクの空き家の改修・引越しの補助 |
