# 007 相場の集計 SQL 関数と 5.1 の値の検証

- 主な要件：5章-4〜7（土地・中古戸建て・件数ラベル・言いかえ）、5.1（現在の集計結果）、9.3（集計は SQL 関数で）
- 依存：006

## 目的

取引データから地区ごとの相場を Supabase の SQL 関数で集計して `market_stats` に保存し、要件 5.1 の表と一致することを確かめる。

## 仕様メモ

- **土地**：種類「宅地(土地)」。㎡単価の真ん中の値（中央値）＋下位25%〜上位25%の幅。㎡単価が空の行は総額÷面積で補う。坪単価（㎡単価×3.3058）と「200㎡（約60坪）なら約○万円」も出せるようにする
- **中古戸建て**：種類「宅地(土地と建物)」で用途に「住宅」を含むもの（空欄も含める）。築年数＝取引年−建築年で「築20年以内」「築21年以上」に分け、総額の真ん中の値。建築年不明はどちらにも入れない
- **件数ラベル**：30件以上「件数じゅうぶん」、10件以下「件数少なめ・参考程度」、11〜29件は提案して決める（案：「参考になる件数」）
- 新しめ（築20年以内）は4地区とも12件以下なので、えらぶ画面の返事に必ず「件数少なめ・参考程度」を付ける（4章）。ラベルの判定を画面側と共通にする
- 集計は取り込みのあとに Worker から RPC で呼ぶ
