# 004 地区マスタと町名→地区の対応表

- 主な要件：2.1（対象地区）、5章-2（地区の振り分け）、7.2（点データの振り分け）、10章（対応表にない町名の対応）
- 依存：003

## 目的

取引・施設などを4地区に振り分けるための対応表を Supabase に入れ、更新の手順を決める。

## 仕様メモ

- 対応表は `iida_district_map.csv`（確認済み）に従う。現在リポジトリに無いので、まさゆきさんに置いてもらう
- 中心市街地 = 丸山・東野・橋北・橋南（上飯田を含む、羽場は含めない）。「松尾町」は松尾地区ではなく中心市街地
- 中心市街地は元の地区名（丸山・東野・橋北・橋南）も持つ（行事の表示で使う）
- 点データ（学校・保育など）は住所の町名を対応表に当てはめて振り分ける。境界線データは使わない
- 対応表にない町名は集計から外し、`unmapped_towns` に記録して管理者に知らせる（通知方法は 005）
