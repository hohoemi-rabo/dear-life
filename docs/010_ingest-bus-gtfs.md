# 010 バス停（GTFS-JP）の取り込み

- 主な要件：7章（バス停）、7.3（GTFS のクレジット）、11.1（ライセンス表示の確認）、4章（車0台の反映）
- 依存：004、005

## 目的

南信州のバスの GTFS-JP からバス停の位置を取り込み、地区ごとのバス停の数と地図表示に使う。

## 仕様メモ

- 入手先：市のページから案内されている GTFS データリポジトリ
- 使うのは `stops.txt`（バス停の名前・緯度経度）。本数や時刻は MVP では出さない
- バス停は住所を持たないので、地区への振り分け方法を決める必要がある（緯度経度から町名を引く、または地区の範囲データを使う）。点データは境界線データを使わない方針（7.2）との関係を整理する
- ライセンス表示は確認中。確認できるまでは公開しない（未確認の間は画面で「データ未取得」扱い）
- 更新は年1回＋ダイヤ改正時
