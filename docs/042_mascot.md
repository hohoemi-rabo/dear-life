## 目的

サイトの9割は既存の移住サービスの集まりなので、残りの1割に、移住とはまったく関係ないけれど「なんか気になる。見たくなる」ものを入れる（2026-11-15 まさゆきさん）。

マスコットを、くらし・カルテ・地区くらべに「気づくか気づかないか」くらいで出す。地区ごとにちがうことをしているので、ほかの地区も見たくなる。押すと服（エプロン）の色を変えられる。

元になった考え：武将の名前が大きく書かれた鍋のもと（味とは関係ないが集めたくなる）と、Meta の Muse（考えている間にアバターが動き、服や色を変えられる。シニアの生徒さんに評判がよい）。

## 決めたこと（2026-11-15 まさゆきさん）

- キャラクターは見本のとおり：しずく形の頭（先がくるんと巻く）、点の目と横線の口、短い手足、肩ひもと後ろのリボンのあるエプロン。はじめの色は見本の青緑
- 絵は `mascot-3d.png` のような立体の絵柄にする。ドット絵にはしない（2026-11-15 まさゆきさん。はじめはドット絵で描き直す案だったが変更）。`mascot-pixel-poses.png` はしぐさの参考にだけ使う
- アニメーションはまさゆきさんが用意する（MP4・GIF・連番の画像のどれでもよい。Claude が画面用の形にする）。画面では数コマの絵を順に切りかえて動かす（見え方は GIF と同じ）。GIF のまま出すと、色を変えるたびに別の GIF が要るため
- 用意してもらうときのお願い：背景は透明、無理なら単色でクリーム色以外（体と同じ色だと背景だけを消せない。おすすめはマゼンタ #FF00FF）。エプロン以外に青緑・青を使わない（そこも色が変わってしまう。黄みのある緑はよい）。長さは1〜3秒で、最後のコマが最初につながるようにする。動きは小さく、1秒に8〜12コマで足りる
- 服の色は、エプロンの青緑の部分だけを選び、明るさ（影・布の質感）を残したまま色だけを替える。アニメーションは青緑の1本だけでよく、色を選んだときに一度だけ置きかえる
- 地区ごとのしぐさ（地区の目印（013）に合わせる）：
  - 上郷：長い石段をほうきで掃いている（見本の左下）
  - 鼎：公園で、ぶらんこをこいでいる、またはすべり台を滑っている
  - 伊賀良：画架に向かって景色を描いている（原田泰治の作品や絵柄には似せない。代替テキストにも名前を出さない。013 の決まり）
  - 中心市街地：りんご並木のりんごを見上げる・拾う（見本の右下）
- くらしだけでなく、カルテと地区くらべでも動かす（表示中の地区のしぐさで出す）
- 押すと色のパレットを出し、色を押すとエプロンの色が変わる。選んだ色は端末の中（localStorage）にだけ残し、くらしで変えた色がカルテ・地区くらべでも同じになる。サーバーには送らない
- 「〇/4地区で見つけた」のような集める印は出さない。ひっそり出すだけにする

## 試したこと（2026-11-15）

`mascot-3d.png` で、重さと色の替え方を試した（写真は `~/dear-life-screenshots/2026-11-15-042-mascot-trial/compare.png`。左から元・赤・黄・紫・ピンク）。

- 重さ：240px（スマホで120px前後に出す大きさの2倍）に縮めると1コマ約2KB。背景を透明にすると1コマ5〜10KBの見込みで、1地区の動き（12〜24コマ）は約50〜200KB。くらしの背景の絵1枚（約500KB）より軽い。読み込むのは表示中の地区の1つだけで、画面が出たあとに読む
- 色の替え方：エプロンの色は rgb(95,119,110) 前後（色相 約157°、彩度が低い）。体のクリーム色は色相 約33°。色相 110〜230°・彩度 0.04 より上の点だけを、明るさを残して目的の色相に替えると、5色とも立体感が残った。エプロンのふちに青緑が少し残るので、実装のときに直す

## 守ること

- 見本（`docs/design/`）にある部品を隠さない・省かない。キャラクターは空いている場所に置く
- 地区くらべで、キャラクターが「この地区がおすすめ」の印に見えないようにする（点数化・おすすめはしない決まり）
- 動きを減らす設定（`prefers-reduced-motion`）の端末では止めた1コマで出す
- 押せる範囲は 44px 以上。押せることがわかる代替テキストを付ける
- 本番に出す前に、絵が既存のキャラクターに似ていないかをまさゆきさんが確かめる（公開リポジトリなので、決まるまで push しない）

## 作ったもの（2026-11-15。上郷のくらし）

- `npm run mascot`（`scripts/build-mascot.mjs`）：`assets/mascot/` の GIF の背景（白に近く黄みの少ない色）を、絵のふちから続くところだけ消し、残った小さな点を消し、全部のコマを同じ範囲で切り出して、横に1列に並べた WebP を `public/mascot/` に書く。大きさとコマ数は `src/lib/mascot/sprites.ts`。上郷は 29コマ・1コマ 155×160・125KB。
- 背景の消し方（2026-11-15 に差しかえた GIF で直した）：GIF は使う色が少なく、背景はちょうど5色で、頭のてっぺんの明るいところとほとんど同じ色だった。「白っぽい色」の幅で消すと頭まで消えるので、全部のコマのふちに出てくる色だけを背景の色としてふちからたどり、そのまわりのにじみ（背景に近い色）は背景から 14px までだけ消す。背景が一色でない（ふちの色が12色より多い）ときは止める
- 画面の部品 `src/components/mascot/Mascot.tsx`：くらしの絵（`IllustratedScene`）の上、ピンより下に重ねる。置き場所は `src/lib/mascot/spots.ts`（動きが届いた地区だけ）。絵が小さいので、押せる範囲は絵に重ねた透明なボタンで 44px まで広げる。絵を読み終えるまで出さず（元の色が一瞬見えないように）、読めないとき（圏外でまだ端末にないなど）は出さない
- `public/illust/` は `npm run illust` が一覧にないファイルを消すので、マスコットは別のフォルダ `public/mascot/` に置いた。Service Worker は生成AIの絵と同じく、使ったときに残す
- 写真：`~/dear-life-screenshots/2026-11-15-042-mascot-kurashi/`（PC・スマホの春と冬、パレットを開いたところ）

## 季節ごとの服装（2026-11-15 まさゆきさん）

- 動きは同じで、服装だけを季節で替える：春は着物風（花の印）、夏はエプロン（はじめの GIF）、秋はニット（葉の印）、冬は毛糸の帽子とマフラー
- 動きの絵は `kamisato-sweep-{spring,summer,autumn,winter}`。くらしの季節の絵ごとに選ぶ（`src/lib/mascot/spots.ts`）。場所・大きさは4季節とも同じ
- 色替えは青緑の部分をまるごと替えるので、冬は帽子とマフラーも一緒に替わる。エプロンではない季節があるので、パレットの見出しを「服の色」にした（コードの名前は apron のまま）
- 写真：`~/dear-life-screenshots/2026-11-15-042-mascot-seasons/all.png`
