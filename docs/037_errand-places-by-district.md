# 037 用事の場所（エリアごと）

- 主な要件：3章（カルテ・F-03）、2.3（スーパー・病院の情報。直す）、4章（車0台の反映）、6.3（バス）、1.1（gofreely）
- 依存：010（バス）、026・031（電車）、008・009（学校）、036（用事の場所の試し版・バス停の名前を出さない決まり）

## 目的

移住を考える人がいちばん気になる「暮らしの用事に、車なしでどう行くか」を、カルテの交通（「車なしで、どう動く？」）で地区ごとに見せる。
036 で作った試し版（4地区共通の5か所）を、まさゆきさんが決めたエリアごとの場所に置きかえる。

## 決めたこと（2026-11-11 まさゆきさん）

- **置く場所**：カルテの交通の「用事の場所」のタブ（036 の試し版と同じ。車0台なら最初に開く）
- **出し方（B 案）**：出発地点（バス停）は決めない。バス停の名前も出さない。行き先ごとに「{地区}のバス停{N}か所のうち{M}か所から、乗りかえなしで行けます　1日{最少}〜{最多}本」（平日の時刻表。行きと帰りの両方に直通便があるバス停を数え、本数はそのバス停ごとの行きの直通便の幅）。1日の本数が大事
- **共通**：市役所（飯田市役所）
- **エリアごと**：病院・診療所（クリニック）・駅・小学校・中学校・高校・買い物
- **診療所（クリニック）**：数だけ出す（まさゆきさんが Google マップで数えた、だいたいの数）。バスの本数は出さない。言い方は「診療所（クリニック）」（まさゆきさんの「町医者」）
- **駅**：その駅から出る電車の本数を出す（地区のバス停から駅までのバスではない）
- **高校**：紹介程度（名前だけ。バスの本数は出さない）
- **小学校・中学校**：エリアごと。バスの本数を出す（これまでの決まり）
- **買い物**：036 で挙げてもらった店。地区をまたいでもよい（西友 伊賀良店は住所が中心市街地、キラヤ 黒田店は住所が上郷）。とりあえず全部載せる。要件 2.3（スーパーの情報は対象外）を直す
- **作り方**：プランを立ててチケットにし、新しいセッションで作る（まさゆきさん）

## 作り方（プラン）

1. **行き先の一覧**（`data/bus_errands.csv`）に「地区」の列（`すべて` か地区名）を足し、種類を 市役所・病院・学校・店 にする。試し版の 飯田病院・健和会病院・飯田駅（共通）は消す。店でそばにバス停がないもの（キラヤ 黒田店）は、バス停を空にして「そばにバス停がないため、バスでは数えていません」と出す
2. **学校のそばのバス停**：学校の住所（位置）から、そばのバス停を出す（店と同じく国土地理院の住所検索と、GTFS の停留所から 450m 以内）。結果の表をまさゆきさんに見せてから一覧に入れる
3. **取り込み**：`npm run bus:sql` が、地区ごとの行き先だけを数えて `bus_errands` に入れる（`has_stop` の列を足す。種類の制約に 学校・店 を足す）
4. **駅の電車の本数**：その駅を出る電車の1日の本数（特急を除く）。電車の時刻（026。2026-11-11 に確認用に公開）から数える。時刻が非公開に戻ったときは、全国鉄道運行本数データ（031）の平日の本数にする（今の電車のタブと同じ決まり）。伊賀良は「地区内に駅はありません」
5. **診療所の数**：手で入れる値として持つ（地区・数・数えた日・数え方）。表示は「診療所（クリニック）約16か所」と、出典の欄に「Google マップで数えた目安（2026-11-11）」。持ち方（新しい表か、手入力の行事・支援制度と同じ形か）は作るときに決める
6. **高校**：名前だけを「近くの高校（紹介）」として出す。学校のデータは市と国の2つの出典が入っているので、画面に出している市のデータ（`iida_education`）だけを使う
7. **画面**：「用事の場所」のタブを、種類ごとのまとまり（市役所・病院／診療所／駅／学校／買い物）で並べる。本数は大きめの数字。いちばん下に gofreely の枠（今のまま）
8. **要件・仕様書・「データについて」**：要件 2.3（スーパー・病院を対象外）を直し、出典（Google マップの数、店の公式ページ）を「データについて」に足す
9. テスト・lint・型チェック・ビルド。Playwright で4地区をスマホ（375px）と PC で見る。本番に出してまさゆきさんが実機で確かめる
